# DefendYourKingdom — документация фактической реализации

**Тип документа:** `IMPLEMENTATION_LOG`; **НЕ PRD и НЕ новая игровая спецификация**. Нормативные требования и запланированные задачи находятся в `spec/`; этот журнал отражает только **фактически выполненную** работу Codex в репозитории. Автор разрешил подготовительный `AUDIT-00`; кодовые задачи M1/M2 по новому плану пока не выполнялись.

## Порядок ведения

- **Одна краткая запись на реально завершённую задачу**, включая её стабильный ID (`A00.01`, `M1.03`, `M2.07` и т. п.). Если задача заблокирована, можно явно записать `BLOCKED` и препятствие, но не выдавать за завершённую.
- По существу: **что сделано; какие технические решения приняты; почему выбран этот вариант**; путь к изменённым ключевым модулям/ассетам; **фактически выполненные** сборка/тесты/ревью и их результаты; известные ограничения.
- Без копирования PRD, длинных трактатов, ложных тестов, искусственных скриншотов и пересказа всех строк кода. Ссылки на ID требования/задачи достаточны; по изменению утверждённых игровых правил нужен отдельный процесс согласования PRD, а не запись в этом журнале.
- Перед каждым commit/push действует локальный QA-гейт из `AGENTS.md`; **packaging и показ игрового результата не обязательны для каждой задачи**. Для невизуальной задачи допустима проверка компиляцией и применимыми тестами. Запуск затронутой игровой сцены — когда он действительно проверяет поведение.
- После работы над задачей оркестратор **кратко сообщает автору то же самое**. Развёрнутый отчёт — на `AUDIT-00`, `M1-SLICE`, `M2-FULL` или при материальном блокере.

```markdown
### [ID задачи] — [краткое название] — [дата] — DONE / BLOCKED
- **Сделано:** [фактический результат и ключевые файлы]
- **Решения и почему:** [до 2–4 предложений с мотивировкой]
- **Проверено:** [команда/действие → фактический итог; тестировщик; ревьюер]
- **Ограничения:** [если есть, иначе «нет известных»]
- **Git:** [хеш коммита после commit; не придумывать заранее]
```

### AUDIT-00 — сопоставление проекта с новым PRD — 14.11.2026 — A00.01/A00.03 DONE; A00.02 PARTIAL / HTTP MCP BLOCKED

- **Сделано:** тематический проход всех 77 файлов `spec/`, инвентаризация Source/Config/Content и окружения; независимые статические тестирование и ревью. Подробности и доказательства — [отчёт аудита](audit-00.md).
- **Решения и почему:** сохранять один модуль и `Core/Meta/Saving`; развивать существующий каркас, адресно доработать профиль/запись/время/слоты. Переписывание проекта не обосновано. Предложены уточнения зависимостей M1/M2 и устаревших QA без изменения PRD.
- **Проверено:** Editor Win64 Development — успешная инкрементальная сборка; headless старт существующей карты/профиля, Simulation и PIE; в обычном PIE подтверждены native-контроллер и камера. - **Ограничения:** HTTP MCP `ue_status` получает 400; native Python-канал работоспособен. Визуальный QA, ввод/UI и полный полигон не проверены; графы/AnimBP и полный UMG layout не подтверждены. Геймплейный код и ассеты не менялись. Допуск к M1/M2 этим аудитом не предполагается.

### TOOLING-MCP — восстановление установленного UE MCP — 15.11.2026 — DONE

- **Сделано:** добавлен `DefendYourKingdom/Config/DefaultRemoteControl.ini`: включён `bEnableRemotePythonExecution`, WebSocket привязан к `127.0.0.1`. Настройка также применена к открытому редактору без перезапуска и изменения ассетов.
- **Решения и почему:** `bRemoteExecution` из прежней настройки разрешал только native Python-канал. Отдельный флаг Remote Control оставался false и запрещал HTTP-доступ к `PythonScriptLibrary` (подтверждено исходниками установленного UE5.5). Включено адресное разрешение, HTTP и WebSocket доступны только локально. Точная причина выбора другого транспорта прежними сеансами MCP не установлена.
- **Проверено:** установленный MCP успешно выполнил `ue_status`, `ue_exec_python`, `ue_list_actors`; status указал `transport=pyremote`. Отдельный прямой HTTP-вызов `ExecutePythonCommand` вернул `ReturnValue=true`, поэтому исходный HTTP 400 тоже устранён. Новый процесс UE5.5 прочитал HTTP Python=true и WebSocket bind=127.0.0.1, commandlet завершился с кодом 0. Артефакты: `Saved/Audit00/mcp-http-repair.json`, `mcp-http-probe.json`, `mcp-cold-config.json`, `mcp-cold-config.log`. Статическое независимое тестирование `audit_test`, ревью `audit_review`.
- **Ограничения:** игровые системы и визуальный QA не затрагивались; полноценные графы Blueprint по-прежнему не подтверждены в UE5.5.
- **Завершение:** по указанию автора в `AGENTS.md` закреплены Changelog, commit и push после каждой выполненной задачи. Changelog обновлён до `0.1.10.0`. Контрольный `Build.bat DefendYourKingdomEditor Win64 Development` завершился с кодом 0 (`Target is up to date`); лог `Saved/Audit00/mcp-commit-build.log`. Материалы оформляются коммитом `Task-14` в `main`; фактический хеш и результат push сообщаются автору после выполнения.
