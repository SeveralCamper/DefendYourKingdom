# QA-группа — Дополнительные проверки площадок и скрытой информации

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## Дополнительные проверки площадок и скрытой информации

| ID | Проверка | Критерий |
|---|---|---|
| `POL-P04-01` | Две площадки с одной условной меткой 2×3, но разными трансформами | Каждая независимо принимает совместимый объект, без глобальной сетки боевого поля |
| `POL-P04-02` | Попытка установить наёмника / ловушку / обычного юнита в несовместимую площадку | Единый механизм отклоняет любую несовместимую пару «объект–площадка», не имеет отдельного исключения для наёмников |
| `POL-P04-03` | Впервые скрытый вход проявился во время волны; затем ещё две волны | Направление видно между волнами только текущей попытки |
| `POL-P04-04` | Перезапуск после раскрытия скрытого входа | Вход снова скрыт; постоянный профиль не сохраняет сведения о нём |
| `POL-P04-05` | На карте две обязательные защищаемые цели; одна разрушена | Немедленное поражение, независимо от здоровья второй |

Все сценарии ещё предстоит выполнить на полигоне; это **запланированные тесты**, а не доказательство работоспособности.
