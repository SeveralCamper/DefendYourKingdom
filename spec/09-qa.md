# 09 — QA: маршрутизатор проверок

**Не читать все QA-сценарии для одной задачи.** Возьми `Task-ID` из `12-execution-backlog.md`, связанные test-ID из `13-requirements-traceability.md`, найди их в `qa/test-index.tsv` и открой **только соответствующие файлы/сценарии**. Полная матрица нужна для интеграционного тестирования полигона и `M2.21`, а не для каждого программного изменения.

```bash
rg -n -F 'P09-T02' spec/qa/test-index.tsv
rg -n -F 'PG-043' spec/qa/test-index.tsv
```
