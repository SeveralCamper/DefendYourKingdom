# 08 — Техника UE5.5: маршрутизатор нормативных разделов

**Для одной задачи выбирайте только технический контракт, который она затрагивает.** Функциональная спецификация важнее общих технологических заметок. Первое исследование реального репозитория — отдельная операция `AUDIT-00`, *не* сделанная этим документом.

- **Runtime:** UE5.5, C++-логика, один модуль `DefendYourKingdom`; Blueprint допустим для UI/анимаций/визуала, когда целесообразен.
- **Первая версия:** только локальная, два чередующихся сейва, временный лицензированный визуал, звук/онлайн позже. Не объявлять реплей/серверный античит существующим.
- **Полигон до финальных карт**, `M1-SLICE` → `M2-FULL` → явный `POLYGON_ACCEPTED` → финальные карты.
