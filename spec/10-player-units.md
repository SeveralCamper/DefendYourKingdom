## Общие линейки и исследования

**Принцип:** игрок исследует T1 → T2 → T3 строго по порядку; в меню размещения по умолчанию выбирается самый сильный открытый ранг, стрелочка над типом позволяет выбрать более низкий. Цена размещения одинакова у всех рангов **одной** линейки. Исследования постоянны и не расходуют боевые припасы.

### Линия пехоты

- Состав: **крестьянин → страж → гвардеец**.
- Цена каждого размещаемого экземпляра, независимо от ранга: **5 припасов**.
- Разблокировка стража: **500 еды / 300 древесины / 200 камня / 0 медалей**.
- Разблокировка гвардейца: **1400 еды / 700 древесины / 500 камня / 10 медалей**.
- Условия открытия (уровень города, кампания и т. п.): **в первичной модели опущены**, не означает их постоянного отсутствия в игре.

### Линия стрелков

- Состав: **лучник → опытный лучник → арбалетчик**.
- Цена каждого размещаемого экземпляра, независимо от ранга: **7 припасов**.
- Разблокировка опытного лучника: **500 еды / 300 древесины / 200 камня / 0 медалей**.
- Разблокировка арбалетчика: **1400 еды / 700 древесины / 500 камня / 10 медалей**.
- Условия открытия (уровень города, кампания и т. п.): **в первичной модели опущены**.

### Общие исследования каждой линии

Приведённые ниже три бонуса **распространяются на все открытые ранги соответствующей линии**, то есть у пехоты и стрелков они приобретаются отдельно. Суммирование с персональными исследованиями по отдельному типу уточняется в момент построения финальной формулы баланса.

| Исследование | Постоянный эффект | Стоимость |
| --- | --- | --- |
| Улучшенное снаряжение | +10 HP | 800 еды + 300 древесины + 500 камня + 5 медалей |
| Стальные заплатки | +1 физической брони* | 1000 еды + 900 древесины + 700 камня + 5 медалей |
| Мурштра | +2 урона | 800 еды + 300 древесины + 500 камня + 5 медалей |

*Броня применяет утверждённое плоское вычитание физического или магического урона; бонус +1 сохраняется.*

### Индивидуальные исследования T2 и T3

- Для каждого **T2**: три независимых постоянных улучшения (+10 HP / +1 брони / +2 урона) **по одному уровню**.
- Для каждого **T3**: эти же три независимых улучшения имеют **по два уровня**, дополнительно открывается **уникальная способность**.
- Цена **каждого шага** индивидуального улучшения временно берётся такой же, как цена соответствующего общего исследования линии. Это первичные цены, автор вправе перебалансировать.
- Для T1 отдельных индивидуальных улучшений сверх общелинейных пока не определено.

## Контроль незакрытых полей

1. **Физическая/магическая броня:** утверждено прямое вычитание P18-Q07; параметры `0…5` сохранены буквально. Дробное округление и взаимодействие с иными модификаторами требуют отдельных проверок.
2. Точные **условия открытия** отсутствуют в первичной модели по твоему решению.
3. Для стрелковых атак: формула задержки попадания по дальности — отдельный технический параметр; не создавать физический Actor-снаряд только ради задержки.
4. Для гвардейца и арбалетчика: указаны **реальные умения и урон**; их недостающие длительности/периодичность/стоимость исследования допускается временно настроить как `DEV_PLACEHOLDER` только для разработческой сборки. Не изменять существующий тип и смысл умений.
5. Для паладина: уровневые приросты/ветви и цены **намеренно отложены**.
6. Для наёмника: личность, название, визуал и дополнительные способности оставлены открытыми; **улучшений нет**.
7. Для всех союзников: заполнить ссылки на 2D/3D модели, анимации, иконки, VFX/SFX; это рабочие адреса будущих ресурсов, а не обязательность готовых ассетов на стадии первичных чисел.

**Правило редактирования:** автор меняет значения паспортов и ссылки. Паспорта в `catalog/allies/` — **единственный источник утверждённых цифр союзных юнитов**; технические заглушки агент хранит отдельно в данных сборки и помечает `DEV_PLACEHOLDER`. После изменения авторских данных заглушка автоматически уступает место утверждённому значению. Указания по разработке — `DEV-MVP-EXEC` в файле `08`, не здесь.
