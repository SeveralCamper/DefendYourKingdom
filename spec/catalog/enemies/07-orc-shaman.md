| Поле | Значение |
| --- | --- |

| Роль/описание | Поддержка Вольных Кланов: область усиления урона; сам способен атаковать. |

**Атаки и способности**

| Поле | Значение |
| --- | --- |
| Основная атака | 5 магический урона; интервал 4 с; дальность 20. |
| Групповое AoE обычной атаки | Нет, если отдельно не указано |
| Автоматическое поведение | Общий FIFO-пул; остановка и атака выбранного защитника, затем продолжение маршрута; при достижении объекта — атакует его до гибели/поражения. |
| Особая способность / аура | Непрерывная аура +20% урона для союзных войск Вольных Кланов в радиусе 10. Однотипные усиления не суммируются. Для DEV-MVP использовать заменяемую `DEV_PLACEHOLDER`-политику округления до ближайшего целого с выбором чётного при точной половине (banker’s rounding); финальный алгоритм требует явного авторского подтверждения. |
| Время/кулдаун особой способности | **НУЖНО ЗАПОЛНИТЬ** |
