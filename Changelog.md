# DYK Change Log

> Компоненты версии назначаются по [правилам версионирования](docs/versioning.md).

**0.0.1.0**
**Added**
- "Коммит 2211086 (Initial commit)" - Создан `README.md` проекта.

**0.0.2.0**
**Added**
- "Коммит c37e6dd (Task-001)" - Добавлены `AGENTS.md`, спецификация игрового цикла, архитектурные паттерны и правила UE5 MCP.

**0.0.3.0**
**Added**
- "План задач MVP" - Создан отдельный план из небольших задач с зависимостями и критериями готовности.
**Changed**
- "Бэклог вынесен из PRD" - Задачи перенесены из `docs/prd_architecture.md` в `docs/mvp_task_plan.md`; архитектурные решения PRD отмечены как требующие проверки.
- "Видение MVP связано с планом" - В `docs/mvp_vision.md` добавлена ссылка на план задач.

**0.0.4.0**
**Added**
- "Коммит e92788e (Task-003)" - Добавлен каркас UE5-проекта: `.uproject`, `Config`, `Source` и `.vsconfig`; `.gitignore` исключает генерируемые каталоги и неиспользуемый Starter Content.

**0.1.0.0**
**Changed**
- "MVP: этап 0 согласован" - Уточнены правила города, офлайн-таймеров, миссий и локального профиля; принят ADR для одного C++ runtime-модуля без Blueprint-классов; подтверждён первый вертикальный срез.

**0.1.1.0**
**Added**
- "MVP-07: структура исходников" - Добавлены каталоги `Core`, `Meta` и `Saving` внутри существующего runtime-модуля.

**0.1.2.0**
**Added**
- "Подключён Unreal MCP" - Включены плагины и настройки Remote Execution для связи Codex с UE5 Editor; сборка проекта проверена через Unreal MCP.

**0.1.3.0**
**Added**
- "MVP-08: контракты размещения" - Добавлены нативные интерфейсы размещаемого объекта и слота, а также UObject-заглушка для проверки допуска.

**0.1.4.0**
**Added**
- "MVP-09: идентификаторы контента" - Добавлены стабильные типизированные ID контента и Data Asset-каталог без значений баланса.

**0.1.5.0**
**Added**
- "MVP-10: локальное сохранение" - Добавлены версионированная схема профиля и подсистема загрузки/создания локального сохранения с защитой от перезаписи повреждённых и несовместимых файлов.

**0.1.6.0**
**Added**
- "MVP-11: часы офлайн-прогресса" - Добавлена подсистема, вычисляющая единый интервал офлайн-времени, сохраняющая отметку расчёта совместно с прогрессом и проверяющая ежедневную награду по локальной календарной дате.

**0.1.7.0**
**Added**
- "MVP-12: запуск в город" - Добавлены стартовая карта цитадели с точкой входа и placeholder-блок-аутом крепости, а также нативный игровой режим, проверяющий доступность локального профиля.

**0.1.8.0**
**Added**
- "MVP-13: камера и выбор" - Добавлены управление камерой WASD/колесом мыши, интерфейс целей игрового выбора и отдельный native delegate для UI-команд.

**0.1.9.0**
**Added**
- "AUDIT-00: аудит проекта (Task-13)" - Добавлен отчёт о соответствии существующего UE5.5-каркаса новой спецификации: карта компонентов, необходимые адаптации архитектуры, уточнения зависимостей M1/M2 и замечания к QA.
**Changed**
- "Журнал реализации" - Зафиксированы фактические результаты сборки, запусков и независимых проверок аудита, включая ограничения HTTP MCP и непроведённые проверки.

**0.1.10.0**
**Fixed**
- "UE MCP: HTTP Python (Task-14)" - Включено отдельное разрешение Python через Remote Control; WebSocket ограничен локальным компьютером. Работа установленного MCP, прямой HTTP-вызов и загрузка настройки в новом процессе UE5.5 проверены.
**Changed**
- "Правила завершения задач" - В `AGENTS.md` закреплены обязательное обновление Changelog, коммит по форме `Task-xxx` и push после каждой выполненной задачи с соблюдением QA-гейта.

**0.1.11.0**
**Added**
- "M1.01: локальная сессия (Task-15)" - Добавлен нативный GameInstance, проверяющий готовность существующих подсистем профиля и офлайн-времени; введена категория логов `LogDYK`.
**Fixed**
- "Безопасный старт города" - При повреждении профиля, несовместимой версии или ошибке записи город не начинает игровую логику и не создаёт игровую либо spectator-камеру. Проверены сборки Editor/Game, холодные запуски и сохранение сессии при переходах между уровнями.

**0.1.12.0**
**Added**
- "M1.02: неизменяемый каталог (Task-16)" - Добавлены типизированные native ID и общие C++-определения четырёх начальных типов юнитов с авторскими числами, отдельными метками DEV_PLACEHOLDER и NotApplicable; сохранена сериализуемая форма ID.
- "Проверки каталога" - Добавлены Automation-тесты ID, сериализации, паспортных значений и совместного чтения неизменяемой базы; проверены сборки Editor/Game и запрет изменения каталога компилятором.
**Fixed**
- "Невалидные категории ID" - Неизвестные значения категории больше не считаются допустимыми идентификаторами контента.

**0.1.13.0**
**Added**
- "M1.03: локальный профиль (Task-17)" - Добавлены две чередующиеся копии USaveGame с ревизиями, версиями и проверкой целостности; создание обеих копий, выбор последней исправной и восстановление отсутствующей резервной копии.
- "Командный сервис профиля" - Введены снимки только для чтения и подтверждаемые записью команды с постоянными ID; повтор события не применяет изменение дважды, ошибка записи не изменяет подтверждённое состояние.
- "Проверки сохранений" - Добавлены Automation-тесты полного round-trip, повторных запусков, повреждений, отказа записи, восстановления и миграции, включая настоящий снимок M1.01.
**Fixed**
- "Безопасный перенос старого профиля" - Существующий однофайловый сейв UE5.5 переносится без изменения оригинала; повреждённые и неизвестные версии не обнуляются. Восстановленная копия допускается к штатному запуску города; офлайн-часы используют командный сервис.
