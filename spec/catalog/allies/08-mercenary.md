## Боевой наёмник — первый тип

| Поле | Значение |
| --- | --- |
| Имя / тип | Первый боевой наёмник; окончательное название TBD |
| Роль | Обычный боец, аналог стража |
| Описание/внешний образ | Наёмник |
| Наличие в городе | Покупаемые/получаемые контракты; улучшений у наёмников нет |
| Коллекция | Запас контрактов на профиль; без игрового лимита количества |

| Интервал | 1,5 с |

### Боевые и контрактные правила

| Поле | Значение |
| --- | --- |
| Основная атака | 12 физического урона, 1 раз в 1,5 с, дальность 5 |
| Уникальные способности | Отложены автором, пока без спецификации |
| Улучшения / уровни | **Нет** (утверждено автором) |
| Расход контракта | При первой запускаемой волне с ещё не использованным наёмником; контракт расходуется однократно |
| Продажа / повторное размещение | В подготовке продаётся с возвратом 100% припасов. Уже использованный в этой миссии наёмник может быть выставлен снова без нового контракта; новая дополнительная единица расходует следующий контракт. |
| Завершение миссии | Расходованные контракты не восстанавливаются при поражении, выходе или перезапуске |
