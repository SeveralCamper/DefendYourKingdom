# QA-группа — P17: художественный контракт и контент

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P17: художественный контракт и контент

**Область:** P17 проверяет также ФИНАЛЬНЫЕ художественные/звуковые ассеты. `P17-T11`, `P17-T12` и аудио-часть `P17-T23` **не входят в локальные M1/M2**, где аудио отключено; не считать их блокерами DEV-MVP.

**Источник нормативных правил:** [`08-tech-and-production.md`](../08-tech-and-production.md), раздел `P17`. Это не тесты «красиво/некрасиво», а проверки соблюдения утверждённых обязательных правил производства и боевой читаемости.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| `P17-T01` | Проверить новый concept task на юнита/здание | Для него сначала существует 2D план-схема / concept sheet, а не только произвольная 3D-заготовка |
| `P17-T02` | Проверить ассет, сделанный по референсу | Итоговый объект оригинален и не является копией чужого готового ассета/UI |
| `P17-T03` | Сравнить три ступени одной линейки защитников | Базовый/улучшенный/элитный варианты визуально различимы, прогресс читается с изометрической камеры |
| `P17-T04` | Сравнить уровни одного здания | Апгрейд меняет внешний вид заметно, а не только число в карточке |
| `P17-T05` | Проверить набор объектов одной фракции | Силуэты/материалы/язык форм позволяют узнавать фракцию как единый визуальный набор |
| `P17-T06` | Убить союзного юнита в бою | Играет анимация смерти; тело остаётся на земле до воскрешения |
| `P17-T07` | Поднять погибшего союзника | Играет анимация воскрешения; юнит возвращается на позицию по боевым правилам |
| `P17-T08` | Убить обычного врага | Играет анимация смерти; затем тело растворяется и исчезает примерно за 4–5 секунд |
| `P17-T09` | Нанести урон разными источниками | В бою не появляются floating damage numbers |
| `P17-T10` | Наложить горение/яд/оглушение/замедление/лечение/бафф | Состояния читаются через анимацию/VFX без обязательных статусных иконок над моделью |
| `P17-T11` | Запустить город, обычный бой и бой с боссом | Для каждого режима используется соответствующий музыкальный слой/тема |
| `P17-T12` | Проверить героя/юнита/врага в нескольких действиях | Есть необходимые SFX атак/срабатываний/каста; речевой озвучки нет |
| `P17-T13` | Открыть ключевые панели HUD/меню | Визуальный стиль соответствует материалам металла/дерева/пергамента |
| `P17-T14` | Попытаться поставить в очередь production-ассет без индивидуального паспорта | Задача блокируется до прохождения `CONTENT-GATE-001` |
| `P17-T15` | Изучить крестьянина → стража → гвардейца по порядку | Все три ранга одной линии; соответствующее оружие — вилы/копьё/алебарда; без одинаковой общей пассивной способности |
| `P17-T16` | Открыть старшую ступень, выбрать тип в HUD | По умолчанию старший изученный ранг; **стрелочка над типом** позволяет выбрать любой изученный младший вариант |
| `P17-T17` | Сравнить стоимость размещения T1/T2/T3 одной линейки | Цена в припасах одинакова для всех трёх рангов (P10), городской апгрейд оплачивается отдельно |
| `P17-T18` | Проверить T1 и T2, затем T3 | Крестьянин и страж без особых способностей; у гвардейца «Размашистый удар» по паспорту `10`, недостающие технические параметры только как помеченные `DEV_PLACEHOLDER` |
| `P17-T19` | Эталонный бой крестьянина с обычным гоблином и четырьмя гоблинами на минимальной сложности | Проверяются исходные цели P10: ≈3 удара/5 с на одного и способность побеждать 4 обычных гоблинов; исходные параметры — по действующим паспортам |
| `P17-T20` | Ввести четыре типа гоблинов | Роли не подменяются; у гоблина-убийцы **15 HP**, у обычного гоблина **10 HP** по паспортам, стрелок — дальний |
| `P17-T21` | Настроить ранний эпизод с 4 типами гоблинов | Массовость обычных гоблинов, высокая ранняя угроза убийцы; не добавлять неподтверждённые способности |
| `P17-T22` | Проверить первую контентную партию | Присутствуют два союзных ряда по три ранга, 13 врагов, паладин, наёмник, тестовый летун и три выбранные ловушки; уже заданные авторские статы `10`/`11` применены буквально, отсутствующие параметры помечены `DEV_PLACEHOLDER`; финальные карты не создаются |
| `P17-T23` | Проверить HUD-иконки, карточки и аудио каждого утверждённого типа | Для каждого реального типа предусмотрены иконка, карточка, SFX атак/смерти, анимации; у врагов дополнительно открываемая запись бестиария |
| `P17-T24` | Проверить неполные паспорта босса, героя, наёмника, гвардейца и ловушек | Уже заданные значения и способности из `10`/`11` сохраняются; незаданные цены/эффекты явно обозначены `DEV_PLACEHOLDER` для **локального разработческого MVP**. Финальная авторская приёмка контента остаётся отдельной |
| `P17-T25` | Попытаться принять полигон только с первым контентным пакетом | `PROD-GATE-001` остаётся `NOT_ACCEPTED` до проверки всех обязательных механик и утверждённого полного объёма контента |
| `P17-T26` | Изучить ранги дальнего боя и открыть боевой выбор | **Лучник → опытный лучник → арбалетчик** изучаются последовательно; доступен старший открытый и выбор младших по стрелочке; размещение рангов одной линейки за одинаковые припасы |
| `P17-T27` | Сравнить базовую экипировку дальних рангов | Лучник — бедная крестьянская одежда, опытный лучник — уровень стража, арбалетчик — уровень гвардейца; детали только после отдельного арт-утверждения |
| `P17-T28` | Создать паспорт босса первой итерации | Выбран **орк-вожак**; исходные **200 HP**, урон **15**, **2 фазы / переход на 50% HP**, **без подкреплений** сохранены по паспорту `catalog/enemies/12-orc-chief.md`; незаполненными остаются индивидуальные умения фаз |
| `P17-T29` | Создать паспорт первого героя | Выбран **воин-паладин**: активный удар молотом по площади (20 урона, радиус 10) указан автором в `10`; личное имя, откаты и иные не заданные детали — `DEV_PLACEHOLDER` |
| `P17-T30` | Испытать базовый тип наёмника | Наёмник — обычный боец-аналог стража в **юнитном слоте**, не сооружение; расход контрактов как в P02/P03 |
| `P17-T31` | Проверить состав ловушек первой итерации | В каталог входят **шипы, падающие брёвна, бомба**; количественные конфигурации ещё не утверждены; продемонстрировать общую многозарядную механику |
| `P17-T32` | Проверить особенность гвардейца | «Размашистый удар» уже задан автором: поражение всех впереди на 10 урона; область/периодичность не заданы и допускаются как `DEV_PLACEHOLDER` в локальной сборке |
