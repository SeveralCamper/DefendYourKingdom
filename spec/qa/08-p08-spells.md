# QA-группа — P08: магия

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P08: магия

**Источник нормативных правил:** [`07-content-and-magic.md`](../07-content-and-magic.md), раздел P08. Все проверки исполняются на полном тестовом полигоне до авторской приёмки `PROD-GATE-001`. `P08-C1` утверждён Q42: эффекты должны завершаться при переходе между волнами; действуют тесты `P08-T15` и `P08-T26`.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| `P08-T01` | Разблокировка условия и исследование заклинания в башне | Открывается после выполнения условий/оплаты, сохраняется в городском профиле |
| `P08-T02` | Получение заклинания напрямую как авторской награды | Доступно как постоянное изученное заклинание без повторного исследования |
| `P08-T03` | Покупка трёх индивидуальных ветвей улучшений | Каждая ветвь влияет только на своё правило; уровни/ресурсы сохраняются |
| `P08-T04` | Особое улучшение с единственной покупкой | Нельзя приобрести повторно; эффект работает по содержанию заклинания |
| `P08-T05` | Башня с недостаточной вместимостью и изучено более 4 заклинаний | В набор можно назначить не больше вместимости и не больше четырёх |
| `P08-T06` | Изучено менее четырёх заклинаний | Набор не заполняется несуществующими заклинаниями |
| `P08-T07` | Попытаться изменить набор во время миссии или между волнами | Набор не изменяется; это действие доступно только в городской башне |
| `P08-T08` | Особое испытание запрещает отдельное заклинание или всю магию | Запрещённое применение блокируется конфигурацией миссии |
| `P08-T09` | На подготовке/паузе нажать заклинание | Каст недоступен; игровое время/откаты соответствуют фазе |
| `P08-T10` | Навести заклинание и отменить нажатием Esc | Выбор отменяется без старта отката |
| `P08-T11` | Навести заклинание и повторно нажать его иконку | Выбор отменяется без старта отката |
| `P08-T12` | Выбрать пустую точку карты, подтвердить каст | Каст принят, откат запущен, нет возврата за отсутствие целей |
| `P08-T13` | Каст с задержкой; враги выходят из зоны до воздействия | Урон/эффект может не попасть, откат остаётся потраченным |
| `P08-T14` | Применять разные заклинания при отдельных откатах | Cooldown независим, боевые валюты при касте не расходуются |
| `P08-T15` | Конец волны при активных откатах и длительных эффектах | Cooldown сбрасывается по P03; активные длительные области и эффекты прекращаются при переходе к подготовке (Q42), не продолжают наносить урон |
| `P08-T16` | AoE против множества перекрывающихся моделей | Все допустимые цели в зоне получают эффект; нет ограничителя количества |
| `P08-T17` | Огненный шар с улучшением на поджог земли | Нанесён основной урон; область затем наносит периодический урон |
| `P08-T18` | Молния с улучшением оглушения | Противники в области получают оглушение, если не имеют иммунитета |
| `P08-T19` | Зелье лечения с улучшением защиты | Подходящие союзные юниты в области лечатся и получают временную защиту; объекты/ловушки/башни не лечатся |
| `P08-T20` | Замедление с улучшением периодического урона | Противники в области замедляются и получают предусмотренный периодический урон |
| `P08-T21` | Сила с улучшением скорости атаки | Союзные юниты в области получают временное ускорение атак |
| `P08-T22` | Заклинание поддержки по союзным призванным существам | Призванные союзным юнитом существа получают разрешённый эффект; нет заклинаний призыва |
| `P08-T23` | Область с несколькими иммунными врагами | Иммунные не получают запрещённый эффект; каст/откат не возвращается |
| `P08-T24` | ×1/×2/×3 с заклинанием с задержкой/периодикой | Синхронизация игрового времени и визуализации; пауза запрещает новые касты |
| `P08-T25` | Запустить миссию с 4 заклинаниями и открыть панель | Только выбранные иконки видны внизу по центру; доступна индикация зоны и отката |
| `P08-T26` | Завершить волну при активном огне по площади, замедлении, яде и иных длительных эффектах, затем начать следующую волну | Все длительные эффекты прекращаются точно на границе волны; ни один статус/область не переносится и не продолжает тикать. Заряды ловушек автоматически не возвращаются. |

**Требование к завершению P08:** `P08-C1` закрыт Q42. Исполнять проверку `P08-T26` завершения длительных эффектов на границе волны; наличие сценария не означает автоматически пройденного теста.
