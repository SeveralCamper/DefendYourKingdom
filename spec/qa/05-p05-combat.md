# QA-группа — P05: атаки, состояния, призывы

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P05: атаки, состояния, призывы

| Сценарий | Действие на полигоне | Ожидаемое поведение |
|---|---|---|
| P05-T01 | Враг проходит мимо защитника вне радиуса | Защитник не движется и не атакует |
| P05-T02 | Враг входит в радиус защитника | Юнит поворачивается и начинает атаковать |
| P05-T03 | Один враг на другой ветке, но в радиусе | Атакуется независимо от маркировки маршрута |
| P05-T04 | Два врага одновременно вошли в радиус | Цель выбрана **детерминированно по порядку регистрации в пуле E09.03**; удерживается до смерти/недоступности |
| P05-T05 | Пока цель жива, появляется более близкий враг | Текущая первая выбранная цель сохраняется, очередь не сортируется по расстоянию |
| P05-T06 | Оба союзных бойца видят одного врага | Обе атаки действуют одновременно; ограничителя нет |
| P05-T07 | Цель вышла из радиуса после начала удара | Уже начатый удар попадает |
| P05-T08 | Цель умерла во время замаха | Удар не перенаправлен на второго врага, нет урона трупу |
| P05-T09 | Запуск ближнего удара | Урон соответствует моменту контакта в анимации, не началу замаха |
| P05-T10 | Дальний выстрел; цель умирает после его «выпуска» | Визуал доходит; отдельного физического снаряда и повторного урона нет |
| P05-T11 | Оглушить атакующего ДО игрового попадания | Ещё не наступившее действие отменяется |
| P05-T12 | Оглушить ПОСЛЕ момента «выпуска» | Уже запущенное визуальное событие не отменяется |
| P05-T13 | Скопить 10+ врагов в одной AoE области | Все допустимые противники поражены, несмотря на пересечение моделей |
| P05-T14 | Союзная AoE включает союзника | Дружественного урона нет |
| P05-T15 | Наложить одинаковое замедление дважды | Нет стека, таймер и эффект обновлены |
| P05-T16 | Юнит погиб до конца волны | Не атакуется, после отката вручную воскресает бесплатно с полным HP |
| P05-T17 | Воскресить юнита среди врагов | Сразу уязвим, временные эффекты очищены |
| P05-T18 | Закончить волну с мёртвыми и ранеными | Все живы и на полном HP без кликов или траты валюты |
| P05-T19 | Призыватель вызывает трёх скелетов | Появление по фиксированному построению, виртуальные позиции |
| P05-T20 | Скелет атакует / получает удар | Действует как обычная боевая сущность; ручной кнопки воскрешения нет |
| P05-T21 | Убить призывателя | Все зависимые существа сразу исчезают |
| P05-T22 | Воскресить призывателя | Построение существ возникает сразу |
| P05-T23 | Продать призывателя и вновь разместить в другом слоте между волнами | Старые призванные удалены; у вновь установленного призывателя существа в правильном построении у новой позиции; нет прямого переноса |
| P05-T24 | Скелет преследует врага в ограниченном радиусе | Он может локально двигаться; родительский юнит не оставляет слот |
| P05-T25 | Ранить двух союзников и активировать лекаря | Лечение нацелено на наиболее раненого (точный критерий P10) |
| P05-T26 | Усилитель видит сражающегося союзника и себя | Выбирает сражающегося, самолечение/самоусиление — последнее |
| P05-T27 | Пауза во время заклинания/умения | Боевые таймеры стоят, нельзя дать новую команду |
| P05-T28 | Проверить ускорение ×1/×2/×3 на массивной сцене | Урон/смерть/попадания корректны, двойные события не возникают |
| P05-T29 | Обычный высокоранговый юнит с пассивной способностью | Способность работает без необходимости перевода в элиту |
| P05-T30 | Повторить убийство вызовом события смерти | Только одно событие исхода и начисление ресурса (связь P02) |
