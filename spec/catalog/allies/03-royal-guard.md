# ПАСПОРТ СОЮЗНИКА — Гвардеец

**Общие правила и исследования:** [`10-player-units.md`](../../10-player-units.md). **Бой:** [`04-unit-combat.md`](../../04-unit-combat.md). **Заполненные параметры не менять без решения автора.**

## Гвардеец — T3

| Поле | Значение |
| --- | --- |
| Имя | Гвардеец |
| Сторона | Защитники игрока |
| Линия / тир | Пехота: крестьянин → страж → гвардеец / T3 |
| Боевая роль | Элитный тяжёлый защитник; ближний бой; есть исследуемая особая атака |
| Оружие | Алебарда |
| Описание внешнего образа | Тяжёлый элитный воин; значительно отличается внешне от стража и крестьянина. |
| Описание для карточки игрока | **НУЖНО ЗАПОЛНИТЬ** |
| Статус | Первичные числа автора; содержимое способностей может быть не полным |

### Базовые параметры

| Поле | Значение |
| --- | --- |
| HP | 35 |
| Физическая броня — исходное значение | 2 |
| Магическая броня — исходное значение | 0 |
| Атака / урон за попадание | 10 |
| Вид урона | физический |
| Интервал атак | 1,5 с |
| Дальность атаки | 5 |
| Задержка нанесения урона | 0,3 с |
| Передвижение в бою | Не перемещается во время волны |
| Стоимость размещения | 5 припасов |
| Откат после смерти | 25 с |

### Атаки, эффекты и особые правила

| Поле | Значение |
| --- | --- |
| Основная атака | Алебарда: 10 физический урона, интервал 1,5 с; радиус 5 |
| Выбор цели | Общий FIFO-пул допустимых целей в радиусе; сохраняет выбранную цель до смерти/выхода (кроме отдельно указанного особого умения). |
| Поражение по площади (основная атака) | Нет (если иное не указано отдельно) |
| Особая способность | Размашистый удар |
| Описание способности | Гвардеец перехватывает алебарду и наносит размашистый удар перед собой; **10 урона всем противникам перед ним**. Тип/форма области, кулдаун, частота автоматического применения и момент срабатывания — **НУЖНО ЗАПОЛНИТЬ**. |
