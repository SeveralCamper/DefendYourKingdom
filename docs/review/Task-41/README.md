# Пекарня: увеличение и hover

Реальный UMG/D3D11: first.png — обычная карточка 506×633, first-hover.png — наведена кнопка «Посетить»; interior.png и interior-hover.png — наведение на первый «Заказать». Тот же класс виджета, исходные текстуры не менялись. Тест вводит настоящий Slate OnMouseEnter и проверяет ненулевую разницу пикселей. Числа — визуальная фикстура Task-40. Внутреннее окно сохранило размер 960×720 в этом рендере. В игре карточка имеет размер до 506×632,5 UI-единиц, центром следует за выбранным зданием и ограничивается краями viewport.
