# 05 — Ловушки, башни и специальные оборонительные сооружения

**Статус:** качественные правила утверждены, стоимость перезарядки по умолчанию (P10) — 5; индивидуальные статы TBD, реализация — P18. **Связанные решения:** `GD-DEC-069…082; PRD06-001…029`.



## 1. Три разных класса назначения обороны

- **Ловушка:** заранее разрешённая площадка, автоматическое срабатывание, ограниченный индивидуальным конфигом запас циклов (`maxUses`/`usesRemaining` — логические имена, не утверждённые UE-поля). Перезарядка игроком возможна **после исчерпания запаса и завершения действия**, за отдельный миссионный ресурс. Во время межволновой подготовки заряды не добавляются автоматически. Ловушки неуязвимы.
- **Башня:** стационарное оборонительное сооружение, без валютной перезарядки, автоматическая атака по скорости/откату. На ней может быть несколько атакующих; у каждого собственная очередь целей по порядку входа в радиус (`E09.03`) и независимый цикл атаки. Башни неуязвимы.
- **Прочие специальные сооружения/юнитные конструкции:** правила берутся из типа. Например, **наёмная баррикада с гномами** — один оборонительный объект с **общим пулом HP**, индивидуальными атаками нескольких гномов; не выдавать гномам отдельные пулы HP из этого описания. Специальные сооружения могут не использовать систему зарядов.

## 2. Срабатывание ловушки

1. Новая размещённая ловушка получает **полный** индивидуально настроенный запас срабатываний. Часто — **2–3 срабатывания**, но это не общесистемный фиксированный предел.
2. При появлении первого допустимого врага в индивидуальной зоне обнаружения ловушка автоматически инициирует цикл, с небольшой задержкой активации (пример автора — 0,25 с; число не утверждено).
3. Одно срабатывание расходует **одну единицу запаса** независимо от числа врагов в зоне поражения. Срабатывание может не попасть, если враг выбежал из зоны к моменту урона. Не вводить «ожидание оптимальной толпы».
4. Урон/эффект применяются в индивидуальный момент относительно начала цикла: параметризованная задержка (например, шипы 0,25 с, брёвна 0,5 с — только иллюстрации). Для длительных ловушек разрешён периодический урон/статусы.
5. Ловушка поражает всех **допустимых врагов в фактической зоне эффекта**, независимо от числа маршрутов и пространственного наложения врагов. Зона триггера, зона урона и габарит слота не обязаны совпадать.
6. Пока цикл действия/длительного эффекта не завершён, не допускать повторного запуска того же цикла или ручной перезарядки. После завершения, если остались использования, ловушка готова к следующей активации.
7. Если запас равен нулю, над ловушкой появляется кнопка перезарядки; при наличии специальной валюты игрок нажимает её, ресурс списывается один раз, запускается короткая анимация, затем восстанавливается полный запас. Если враг остаётся внутри зоны, новый автоматический цикл может начаться немедленно после возвращения в готовность.
8. При окончании волны **немедленно прекращаются все продолжающиеся воздействия** (урон/зона эффекта). Количество оставшихся срабатываний **не меняется** от самого факта окончания волны или паузы. Прямое перемещение ловушек запрещено (P16); заново купленная ловушка начинает с полным запасом.

**Отдельно:** враги, призванные вражескими призывателями, активируют ловушки и получают урон, хотя не дают валюту за убийство (`GD-DEC-027`). Игрок не нажимает кнопку ручного *срабатывания* ловушки. Нет дружественного урона (`GD-DEC-056`).

## 3. Состояния для проектирования (не схема C++)

| Состояние | Вход | Доступные события | Переход |
|---|---|---|---|
| `READY` | Есть оставшиеся использования, нет исполняемого цикла | допустимая цель в области → триггер | `TRIGGER_PENDING` |
| `TRIGGER_PENDING` | Первый враг инициировал автоматическое срабатывание | истекла задержка/наступило действие | `ACTIVE` или завершение одного мгновенного удара |
| `ACTIVE` | Выполняется анимация/длительное воздействие | эффекты и периодические тики | `READY`, если остаток >0, иначе `EMPTY` |
| `EMPTY` | Остаток равен 0 и цикл завершён | кнопка при достаточной валюте | `REARMING` |
| `REARMING` | Ресурс списан, идёт анимация перезарядки | завершение | `READY` с полным запасом |

В таблице состояния обозначают логические различия; конкретные события в одном кадре/тайминги и транзакционность прорабатываются в P18. Длительный эффект завершается на границе волны без бесплатного пополнения запаса.

## 4. Продажа, изменение позиции через новое размещение, блокировка абуза

- Правила P02/P16: разрешённая продажа возвращает 100% припасов размещения; ресурс перезарядки не возвращается; **прямого переноса или drag-and-drop между слотами нет**. Для новой позиции нужно продать объект (если продажа допустима), затем купить заново в другом совместимом слоте **с полным количеством зарядов новой ловушки**. Покупки/продажи только в подготовке.
- **Продажа разрешена только при `remaining == max`** (если текущая фаза разрешает продажу и ловушка является объектом игрока). При `0 <= remaining < max` действие запрещено (`GD-DEC-082`).
- Частично израсходованную ловушку нельзя продать: остаток расходуется обычными автоматическими срабатываниями, затем при 0 выполняется **полная платная перезарядка**; только после неё продажа снова доступна. Дозарядки при `0 < remaining < max` нет.
- В меню разряженной ловушки — уже утверждённое сообщение «Для продажи сначала перезарядите». Для частично использованной ловушки показываем неактивную команду продажи; точную формулировку интерфейса определим в P16 без изменения правила.
- При разрешённой продаже возвращается ровно 100% припасов размещения. Валюта ранее выполненной перезарядки никогда не возвращается.

## 5. Башни и мультиатакующие сооружения

- Автор карты может заранее разместить башню; такая башня является **неинтерактивной частью сценария**: у игрока нет продажи/перемещения/покупки. Башня остаётся способной атаковать согласно авторским настройкам.
- В редких миссиях игрок может установить башню в совместимый слот за припасы и между волнами **продать и приобрести заново в другом слоте**; отдельной команды перемещения/перетаскивания нет (P16).
- Каждый боец на башне использует **свой упорядоченный пул целей по E09.03**, атакует первую допустимую цель и удерживает её до потери допустимости. Разные бойцы могут одновременно атаковать одного врага. Физические снаряды не моделируются.
- Башня не получает урона; атакуемая баррикада с гномами **не башня в смысле неуязвимого объекта**: это специальная цель с одним пулом HP и несколькими атакующими.
- Область поражения, дальность и габарит слота независимы, все площадки вручную задаются автором карты (P04).

## 6. Прогрессия и бонусы

- Открытие старшего варианта ловушки **не удаляет** младший. Обычный → улучшенный → элитный остаются доступны, если изучены.
- Ранее открытые ступени войск и ловушек остаются доступны; **выбор ранга обычного войска** через стрелочку над типом описан в [`UI16.01`](02-mission-economy.md#ui1601--выбор-миссии-и-подготовка). **Отдельный способ выбора вариантов ловушек** здесь не утверждён: не переносить без решения автора интерфейсную стрелочку войск на ловушки.
- Элитные уникальные способности ловушек **автоматические**, без ручной кнопки способности.
- Постоянные бонусы городской прогрессии применяются ко всем подходящим экземплярам, не начисляются вручную на каждую единицу. Конкретные условия действия бонусов — P14.
- Уникальные миссионные ловушки возможны без городской разблокировки, если явно предоставлены конфигурацией миссии.

## 7. HUD, обратная связь

- Над моделью каждой интерактивной ловушки **виден счётчик оставшихся использований**; при 0 появляется иконка перезарядки.
- Если ресурса не хватает, иконка остаётся затемнённой и не принимает клик, без отдельного всплывающего объяснения.
- Перезарядка воспроизводит краткую анимацию, а после её завершения ловушка снова готова.
- Невозможная продажа при 0 объясняется текстом «Для продажи сначала перезарядите»; при `0 < remaining < max` продажа также недоступна (`GD-DEC-082`).
- Предварительно установленные автором сооружения и бойцы — не интерактивные слоты покупки/перестановки; не создавать для них стандартное меню продажи.

## P17 — Три ловушки первого контентного пакета

**APPROVED — состав:** **шипы, падающие брёвна, бомба**. Для каждой требуется отдельный паспорт по `CONTENT-GATE-001`: индивидуальные циклы срабатывания/заряды, область обнаружения и поражения, задержка, длительность, урон/эффекты, перезарядка, размеры/допустимые площадки, улучшения, визуал и SFX. **Никакие новые значения или особые способности этим трём типам пока не назначены.** Общая многозарядная механика данного файла действует без исключений, пока автор не установит конкретное правило ловушки. На полигоне должны проверяться и другие утверждённые виды механик, если трёх выбранных типов недостаточно.

## 8. Базовые параметры P10 и оставшиеся границы

**Утверждено:** стоимость **полной ручной перезарядки ловушки по умолчанию — 5 единиц** отдельного миссионного ресурса. **У каждой конкретной ловушки может быть своя стоимость**; 5 — базовая настройка, не фиксированная цена всего класса. До `remaining == 0` частичной дозарядки нет. Урон мощной ловушки может мгновенно убивать базового гоблина при успешном попадании, но это не обязательно для каждой ловушки.

Не придумывать конкретные `maxUses` (кроме настроек отдельных подтверждённых вариантов), длительности триггера/урона/перезарядки/периодических тиков, стоимость размещения, площадь и значения спецэффектов — это индивидуальные поля контента. Точный контракт состояния и обработка границы волны/паузы — P18.
