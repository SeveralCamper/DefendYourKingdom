## DEV-MVP: временные данные

**Источник:** [`DEV-MVP-EXEC`](../tech/05-dev-mvp-policy.md). Эти проверки касаются рабочего разработческого MVP; они не подтверждают финальный баланс или арт.

| ID | Проверка | Критерий |
|---|---|---|
| `DEV-T01` | Каталог содержит незаполненную автором цену здания | Система загружается и работает со значением `DEV_PLACEHOLDER`, нет hard-fail и нет бесплатного неограниченного дублирования из-за отсутствующей цены |
| `DEV-T02` | Изменить placeholder цены/HP/кулдауна в данных | Поведение изменяется без переписывания C++-алгоритмов |
| `DEV-T03` | Значение уже заполнено в авторском паспорте `10`/`11` | Применяется авторское значение; placeholder его не перезаписывает |
| `DEV-T04` | Присвоить новый авторский параметр вместо placeholder | Новое значение подхватывается без изменения правил системы и не теряется |
| `DEV-T05` | Броня `0…5` и два типа урона | Прямое вычитание выбранной брони, `0` не защищает, большой Armor не порождает отрицательный урон |
| `DEV-T06` | Мгновенная dev-строительная операция | Работает при длительности 0, сохраняет правильные списания/возвраты и состояния, без искусственных ожиданий |
| `DEV-T07` | Стрелочный выбор ранга и единый слот «юнит» | Все обычные игроковые ранги/герой/боевой наёмник используют одинаковый тип слота; доступность перемещения определяется картой |
| `DEV-T08` | Встречается заглушка модели/иконки/VFX/SFX | Система не падает; есть безопасный fallback, невозможно принять тестовый арт за финальный |
| `DEV-T09` | Временные имена/описания контента | Никаких новых канонических фракций/игровых механик не введено |
| `DEV-T10` | Пользователь покидает полигон без финального контента | `POLYGON_ACCEPTED` не выставляется автоматически; финальные карты не созданы |
| `DEV-T11` | Запустить несколько волн MVP-заглушки endless, выйти в город, вернуться | Состояние межволновой подготовки сохранено, волны запускаются; нет ложной гарантии рейтингов/долговременного endless |
| `DEV-T12` | Проверить в одном прогоне режим пятого испытания и завершение длительных заклинаний | У каждого защищаемого объекта `CHALLENGE_5` MaxHP=HP=1 (Q41); на границе волны эффекты очищаются (Q42); результаты тестов не подменяются отметкой PASS без запуска |
