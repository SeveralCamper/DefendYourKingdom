# Общий HUD ресурсных зданий

Все строки `DYKCityCatalog::Buildings()` с категорией `Production` используют один
`UDYKResourceBuildingWidget` и один asset
`/Game/DefendYourKingdom/Art/ResourceHUD/ProductionTemplate`.
Пекарня, лесопилка, каменоломня и кузница используют общую разметку окон.
Мастерская, казармы и башня волшебника используют тот же класс виджета
и отдельный общий макет `MilitaryPopup` для карточки на карте.
Дом, производящий золото, относится к категории `House` и в этот шаблон не входит.

## Разделение ответственности

- **Шаблон:** две цельные авторские подложки, размеры, прозрачные области действий
  и слоты текста и иллюстраций. Всё расположение находится в общем data asset.
- **Данные типа:** название здания, название продукта, ресурс и заменяемые параметры
  производства находятся в `DYKCityCatalog`. Хлеб остаётся визуальной формой еды.
  Текстуры материалов во внутреннем окне перечислены по ID здания в `ProductionTemplate`.
- **Данные экземпляра:** GUID, накопления, очередь, таймер и допустимость действий
  формирует `UDYKCityWorkWidget::ResourceView` из профиля и существующих правил.
- **Команды:** единый обработчик `ResourceAction` вызывает существующие сервисы
  заказов, сбора, строительства и перемещения. Виджет не меняет профиль сам.

Чтобы добавить следующий производитель, нужна строка каталога с категорией
`Production`. Новый класс виджета, копия layout и ветка по ID здания не нужны.
Для внутреннего окна `InteriorIllustrations` содержит массив текстур по ID
здания. Порядок текстур совпадает с порядком рецептов слева направо.
Контроллер передаёт каждую текстуру вместе с данными соответствующего заказа.
При отсутствии текстуры остаётся видна общая подложка карточки.

## Состояния

Карточка на карте центрируется на выбранном здании и помещается в область экрана.
Под заголовком ресурсной карточки расположены накопления, очередь и время
в часах и минутах. Военная карточка показывает название работы и остаток
времени. Если работа стоит в очереди, время заменяется надписью «Ожидает».
Посещение открывает внутреннее окно по центру экрана.
Золотая подсветка доступной кнопки следует её рамке.
Для недоступных «Собрать», «Улучшить здание», «Отменить работу» и «Заказать»
подставляется серая графика. Недоступные кнопки не подсвечиваются и
не принимают нажатия. Все четыре слота заказа используют одну пару текстур
с общей маской рамки и одним размером 224×69.
«Посетить» всегда доступна и остаётся красной.

После завершения заказа счётчик, индикаторы и кнопки открытого окна
обновляются по сохранённой очереди. Заказ, чей результат ещё не поместился
во внутренний накопитель, продолжает занимать слот.

`prepare_building_popup_art.ps1` готовит две компактные авторские подложки,
очищая только примеры текста и чисел и создавая серые состояния кнопок.
`prepare_production_recipe_art.ps1`
извлекает изображения материалов из авторских `*EnterenceHUD.png` в
`SourceArt/CityHUD/ProductionTemplate/RecipeArt`. Для другого расположения
исходников скрипт принимает `-ReferenceDirectory`.
`prepare_production_hud.ps1` убирает примеры чисел и подготавливает состояния
кнопок. `import_production_hud.py` создаёт общий asset со слотами и таблицами
иллюстраций.

Кузница использует `RES-IRON`, ту же очередь и сбор. При загрузке города без
кузницы стартовая кузница занимает ближайшее к (32, 22) свободное место на
открытой территории. Размещение сохраняется в профиле. Если участок полностью занят,
город загружается с текущей расстановкой. Числа кузницы остаются `DEV_PLACEHOLDER`.
