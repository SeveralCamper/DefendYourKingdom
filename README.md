# DefendYourKingdom — игровая спецификация

**Назначение:** рабочий, актуальный PRD для Unreal Engine 5.5; не журнал обсуждений. Игровая логика на C++; UI/анимации/визуал могут использовать Blueprint при технической необходимости. Полная документальная подготовка выполнена; приступить к коду можно **только по прямому допуску автора**.

## Быстрый маршрут для агента (без чтения лишнего)

1. Один раз прочти **[`AGENTS.md`](AGENTS.md)** и краткие рамки [`spec/00-project-and-roadmap.md`](spec/00-project-and-roadmap.md).
2. Найди **одну** назначенную задачу в [`spec/12-execution-backlog.md`](spec/12-execution-backlog.md); по [`spec/13-requirements-traceability.md`](spec/13-requirements-traceability.md) получи *только* её требования и тесты.
3. Выбери **предметные** файлы по таблице ниже, затем, только если задача реально касается сущностей, — их отдельные **паспорта** в [`10`](spec/10-player-units.md) или [`11`](spec/11-enemy-units.md).
4. Выбери только применимые технические разделы из [`08`](spec/08-tech-and-production.md), QA — из [`09`](spec/09-qa.md), а не целиком каталоги.
5. Реализуй и проверь задачу, обнови [`docs/implementation-log.md`](docs/implementation-log.md). Следующая задача — **новый узкий набор контекста**, без копирования всего PRD.

### Маршрутизатор по предмету

| Если задача касается… | Точка входа | Дополнительно только при необходимости |
| --- | --- | --- |
| Города, стройки, жителей, ресурсов, исследований | [`01-city-and-meta`](spec/01-city-and-meta.md) | `10` — стоимость открытий типов; технический раздел сохранений/таймеров |
| Миссий, припасов, контрактов, наград, режимов, HUD | [`02-mission-economy`](spec/02-mission-economy.md) | `03` — карта; `07` — волны и способности |
| Путей, слотов, маршрутов, защищаемых объектов | [`03-battlefield`](spec/03-battlefield.md) | `04` — момент попадания; `07` — AI |
| Базового урона, брони, атак, смертей и воскрешений | [`04-unit-combat`](spec/04-unit-combat.md) | Только затронутые паспорта в `10`/`11` |
| Ловушек, башен и специальных сооружений | [`05-traps-and-towers`](spec/05-traps-and-towers.md) | `02` — ресурсы; `07` — контент/эффекты |
| Героев и активных умений | [`06-heroes`](spec/06-heroes.md) | Паладин — отдельный паспорт через `10` |
| Заклинаний, врагов, волн, боссов, бестиария | [`07-content-and-magic`](spec/07-content-and-magic.md) | Только конкретные паспорта в `11` |
| Паспорта союзного типа | [`10-player-units`](spec/10-player-units.md) | Один файл `spec/catalog/allies/` |
| Паспорта типа врага | [`11-enemy-units`](spec/11-enemy-units.md) | Один файл `spec/catalog/enemies/` |
| UE5 архитектуры, сейвов, сборки, ассетов, онлайн-границ | [`08-tech-and-production`](spec/08-tech-and-production.md) | Один нужный файл `spec/tech/` |
| Регрессий, полигона, приёмки | [`09-qa`](spec/09-qa.md) | Конкретный `spec/qa/*.md` по `spec/qa/test-index.tsv` |
| Открытых авторских данных и тестовых заглушек | [`OPEN_FIELDS`](spec/OPEN_FIELDS.md) | Только соответствующий паспорт |

**Роли:** оркестратор читает задачи/зависимости; исполнитель — одну задачу, относящиеся правила/паспорта; тестировщик — связанные QA-ID; ревьюер — diff, контракт, результаты проверки. **Каталоги `catalog/`, `qa/`, `tech/` не загружать целиком.** `AUDIT-00` — исключение для первичной полной инвентаризации: проверяет весь PRD и реальный проект *по частям*, фиксирует карту компонентов, но не передаёт всю документацию каждому субагенту.

## Стадии

`AUDIT-00` (после прямого допуска) → `M1-SLICE` → `M2-FULL` → ручной тест и явное `POLYGON_ACCEPTED` → финальные карты. Steam store page — после играбельного M2; сервер, аудио, рейтинги и реплеи — позже. Точный объём — [`00`](spec/00-project-and-roadmap.md), [`12`](spec/12-execution-backlog.md).
