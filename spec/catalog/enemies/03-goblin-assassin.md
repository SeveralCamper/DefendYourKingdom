### Гоблин-убийца

| Поле | Значение |
| --- | --- |
| Отображаемое имя | Гоблин-убийца |
| Фракция / категория | Вольные Кланы / Гоблины |
| Роль/описание | Быстрый опасный «стеклянная пушка», без отдельной способности. HP 15 согласно первичному паспорту; быстрее обычного гоблина. |
| Текст для бестиария | **НУЖНО ЗАПОЛНИТЬ** |
| Тип перемещения | По маршруту, наземный |
| Сюжетное использование | Волны кампании Вольных Кланов; конфигурация отдельных миссий задаётся отдельно |

**Атаки и способности**

| Поле | Значение |
| --- | --- |
| Основная атака | 2×3 физический урона; интервал 2 с; дальность 5. |
| Групповое AoE обычной атаки | Нет, если отдельно не указано |
| Автоматическое поведение | Общий FIFO-пул; остановка и атака выбранного защитника, затем продолжение маршрута; при достижении объекта — атакует его до гибели/поражения. |
| Особая способность / аура | Нет |
| Время/кулдаун особой способности | — |
| Дополнительные статусы / иммунитеты | **НУЖНО ЗАПОЛНИТЬ** |

**Серия ударов:** `2×3` — две составляющие по 3 урона, с общим интервалом атак 2 с. Тайминги двух попаданий — **НУЖНО ЗАПОЛНИТЬ** (для DEV-MVP `DEV_PLACEHOLDER`); применение плоской брони проверять для каждого отдельного события попадания.
