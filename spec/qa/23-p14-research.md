# QA-группа — P14: исследования и прогрессия

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P14: исследования и прогрессия

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| `P14-T01` | В конфигурации нового бойца задать два составных условия, выполнить только одно | Тип ещё закрыт; откроется после выполнения обоих условий |
| `P14-T02` | Попробовать открыть элитную ступень без базовой/улучшенной, затем попытаться начать разрешённое исследование при нехватке одного ресурса | Порядок линейки соблюдается. При нехватке ресурса кнопка не принимает нажатие, команда не добавляет заявку. При точном остатке по цене исследование доступно |
| `P14-T03` | Открыть элитную ступень после предыдущих | Все ранее изученные ступени остаются доступными в миссии |
| `P14-T04` | Исследовать улучшение конкретной линейки | Эффект получает только линейка/тип, указанные авторскими данными, другие не меняются |
| `P14-T05` | Начать исследование при занятых строителях | Одна независимая ячейка исследования работает без строителей; второе исследование ждёт освобождения ячейки |
| `P14-T06` | Отменить ещё не завершённое платное исследование | Полный возврат реально списанных ресурсов, исследование не разблокировано |
| `P14-T07` | Проверить согласованную модель Q40 после возобновления игры и при занятой очереди | Строители, исследования, очереди и офлайн-таймеры работают по временной модели; не превращаются в мгновенное развитие |
| `P14-T08` | Улучшить башню волшебника до следующего уровня | Открываются предусмотренные конфигурацией новые слоты до лимита 4 без отдельной покупки |
| `P14-T09` | Попробовать купить ступень улучшения героя до нужного уровня | Покупка недоступна, стоимость не списана; после требуемого уровня доступна |
| `P14-T10` | Замок уровня 1, владение одним стартовым домом, построить ещё два | Разрешено иметь три дома; не включать автоматически дополнительные лимиты из старого «один тип = один экземпляр» |
| `P14-T11` | Перенести декоративное бонусное здание во временное хранилище редактора, затем вернуть | Бонус исчезает на время снятия и восстанавливается после размещения |
| `P14-T12` | Продать декоративное здание | Возвращено 100% уплаченных городских ресурсов, экземпляр удалён из владения, бонус отключён |
| `P14-T13` | Попытаться продать функциональное здание | Операция запрещена; можно только бесплатно переставить/временно снять |
| `P14-T14` | Получить контракт наёмника за миссию, из события и за золото | Каждый предусмотренный источник создаёт правильный постоянный баланс контракта без дублирования |
| `P14-T15` | Покупка контракта до выполнения индивидуальных условий открытия вида | Запрещена до разблокировки; после разблокировки — разрешена при достаточном золоте |
| `P14-T16` | Накопить большое количество контрактов одного типа | Отсутствует произвольный геймплейный MaxStack; числовое представление не переполняется |
| `P14-T17` | Проверить 100% отмену исследования на границе завершения/двойным кликом | Не происходит двойного возврата или завершения одновременно с отменой |
| `P14-T18` | Взять утверждённый конкретный объект с паспортом CONTENT-GATE-001 | Все обязательные для данного объекта параметры, улучшения, эффекты и тесты определены и связаны с его стабильным ID |

**Статус:** эта матрица — нормативные сценарии будущего полигона, не свидетельство реализованных/пройденных тестов. Вопрос `TIME-MODE` закрыт Q40; статус `PASS` допустим **только после фактического исполнения соответствующих тестов**. `CONTENT-GATE-001` обязателен до интеграции финального объекта, `PROD-GATE-001` — до создания кампанийных и бесконечных карт.
