# Эталон ресурсного HUD: пекарня

Оба исходника из сообщения автора сохранены без изменения в `DefendYourKingdom/SourceArt/CityHUD/Bakery/ReferenceFirst.png` (1122×1402) и `ReferenceInterior.png` (1448×1086). Это именно вложения, не отличающиеся от них файлы из concept-arts/HUD. Генерация изображений не использовалась.

`Tools/slice_bakery_hud.ps1` буквально копирует прямоугольники исходников в PNG без изменения размеров и фильтрации. `slices.json` хранит координаты/действия, `hashes.json` — SHA256 результатов. Статические кнопки с надписями, описание в рамке, иллюстрация, заголовок, декоративные элементы и карточки заказов сохраняют исходную графику. Для живых накоплений/очереди/таймера примеры чисел удаляются копированием соседней пустой кожи на той же строке. Ресурсный значок отделён от общей зелёной кнопки. Внешний чёрный фон второго вложения удаляется связной маской; сами объекты не перерисовываются.

Импорт: `Tools/import_bakery_hud.py` через скрытый UE Python-процесс с NullRHI. В Content импортируются только используемые срезы. Корень: `/Game/DefendYourKingdom/Art/ResourceHUD`.

Архитектура:

- `UDYKResourceBuildingWidget` — один независимый UI-объект для первичного/внутреннего окна. Получает описание оформления, `FDYKResourceBuildingView` и отправляет события `OnAction`; не читает профиль и не изменяет экономику.
- `UDYKResourceHUDDefinition` — конфигурация изображений, координат, исходных размеров и ролей элементов. Пекарня — asset `Bakery`; `Catalog` связывает тип здания с конфигурацией. Следующий производитель использует этот же класс и те же кнопки, ссылаясь на существующие срезы, а свои заголовок/описание/иллюстрации получает из нового референса. Код виджета для этого не копируется.
- `UDYKCityWorkWidget` — адаптер событий/состояния. По GUID выбранного здания рассчитывает доступность сбора/улучшения, накопления, очередь и таймер; команды остаются в прежних C++-сервисах. Старые события снятого виджета блокируются поколением и отключением делегата.
- Первичная карточка центрируется на проекции Bounds.Origin меша выбранного здания, следует за камерой и ограничивается краями экрана. При ширине рабочего viewport 1920 и высоте 1080 максимальный размер карточки 506×632,5 UI-единиц. Нажатия вне неё доступны городу. Внутреннее окно модальное, центрировано; область .025…975 уменьшена ровно в 1,5 раза до .183333…816667. «Назад» — исходный синий кружок под крестиком.

Пекарня сохраняет технический `CITY-MILL`, GUID, уровни, накопления и заказы прежней мельницы. Хлеб — представление `RES-FOOD`; новый баланс не добавлен, 3D-модель не менялась. Прежние производители не переключены на пекарную графику.

Проверки: `DYK.BakeryHUD.BindingAndCommands`, `ContentAndAnchoring`. Отдельный `RenderReferenceWindows` реально рисует тот же UMG-виджет через D3D11/FWidgetRenderer, читает GPU render target, проверяет цвет пергамента и прозрачность и сохраняет PNG. Под NullRHI этот тест явно пишет NOT_RENDERED, его нельзя считать визуальным прогоном. Нормальный D3D11-запуск выполняется скрытым процессом; `-RenderOffscreen` в данном окружении вызывал сбой D3D11 при старте редактора.

Снимки в `docs/review/Task-40/` — реальный UMG, без дорисовки после экспорта. Предпросмотр использует демонстрационную модель: 2150 в здании, 1/3 заказа, 53 мин 24 с; в игре эти поля получают состояние выбранного экземпляра. Итоговая авторская приёмка остаётся отдельной.

Task-41: первичная карточка увеличена на 15%. SResourceButton рисует мягкий золотой контур только при наведении или клавиатурном фокусе доступной кнопки; круглые Close/Back получают круговой контур. Исходные текстуры, hit-area и геометрия контента не меняются. Размер вычисляется общим PopupSize с ограничением viewport.

Task-42: кнопки сохраняют hover при временной недоступности действия, но проверка bActionAvailable блокирует игровую команду и выводит причину. Первая карточка получает обычную авторскую рамку без запечённого свечения. Контур Back смещён к фактическому центру круга, исключая нижнее прозрачное поле среза. Отмена производства выполняется транзакционно по GUID текущего заказа, отдельно от отмены стройки.
