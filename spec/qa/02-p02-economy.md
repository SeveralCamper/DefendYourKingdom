# QA-группа — P02: экономика и контракты

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P02: экономика и контракты

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| `QA-P02-01` | В подготовке купить изученный обычный юнит за X припасов и затем продать | Списано X, возвращено X; слот освобождён, тип остаётся открытым |
| `QA-P02-02` | Продать героя, предварительно разместив за X | Возврат X; никакого уровня/XP героя внутри миссии не меняется, так как их нет |
| `QA-P02-03` | В подготовке выставить нового наёмника и снять до старта волны | Возврат припасов, контракт только освобождён из резерва, не списан |
| `QA-P02-04` | Начать волну с новым наёмником; затем следующую с тем же | Один контракт списан при первом старте, повторного списания нет |
| `QA-P02-05` | Продать активированного наёмника после волны и поставить снова | 100% припасов возвращено при продаже, при постановке снова списаны; новый контракт не тратится |
| `QA-P02-06` | С активированным наёмником выставить второго нового того же типа | Второй занимает другой допустимый слот; второй контракт будет списан при первом его старте волны; первый не дублирован |
| `QA-P02-07` | Продать активированного наёмника и не выставлять до конца миссии | Отряд исчезает по завершении миссии, контракт не возвращается; специального предупреждения нет |
| `QA-P02-08` | Перезапустить миссию после участия наёмника | Потраченные контракты не возвращаются, временные отряды старой попытки не переносятся |
| `QA-P02-09` | Отменить миссию до первой волны при зарезервированных наёмниках | Контракты остаются в постоянном запасе, резерв снимается |
| `QA-P02-10` | Установить новую ловушку | Ловушка изначально заряжена; ресурс перезарядки миссии по-прежнему 0 |
| `QA-P02-11` | Последний заряд ловушки израсходован, волна закончилась | Ловушка разряжена и в следующей подготовке; продажа отклоняется |
| `QA-P02-12` | Попытаться прямо перенести разряженную ловушку либо продать её ради перестановки | Прямого переноса нет для всех размещённых объектов (P16); продажа разряженной ловушки запрещена; заряд, ресурсы и слот не меняются |
| `QA-P02-13` | Перезарядить ловушку за Y ресурса, затем продать в подготовке | Возврат X припасов установки, ресурс Y не возвращён |
| `QA-P02-14` | Пройти волну с фиксированной выплатой Z при разном HP объекта/количестве убийств | Выплата припасов Z в каждом случае, без бонуса эффективности, однократно |
| `QA-P02-15` | Не тратить припасы две волны подряд | Остаток суммируется без игрового потолка; при начале другой миссии старый остаток не переносится |
| `QA-P02-16` | Начать новую миссию | Ресурс перезарядки = 0, стартовые припасы из данных миссии |
| `QA-P02-17` | Убить обычных врагов разными источниками урона | Однократная выплата ресурса перезарядки по конфигурации типа врага |
| `QA-P02-18` | Убить призванного врагами юнита | Ресурс перезарядки не увеличивается |
| `QA-P02-19` | Убить врага и получить дублирующий callback смерти | Награда выплачивается однократно |
| `QA-P02-20` | Повторно продать тот же объект, купить при недостатке припасов, запустить запрещённую в текущей фазе операцию | Балансы, контракты и слоты остаются неизменными |
| `QA-P02-21` | Совершить произвольное число допустимых продаж/повторных покупок в подготовке | Нет лимита операций и дополнительных пошлин; прямой перенос между слотами отсутствует |
| `QA-P02-22` | Погибший юнит после отката поднят во время волны; затем завершить волну с павшими и ранеными | Воскрешение бесплатно; в межволновой фазе все юниты живы с полным HP; ловушки не восстанавливаются |
| `QA-P02-23` | Показать меню выбора обычного и наёмного юнитов | У обычного счётчика экземпляров нет, у наёмного количество отображается |
