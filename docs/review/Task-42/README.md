# Состояния кнопок пекарни

Настоящий UMG/D3D11, без изменения экспортированных PNG. first/interior — обычные окна. first-hover — Посетить; interior-hover — Заказать при очереди 3/3. hover-4 — Собрать при недоступном сборе; hover-6 — недоступное улучшение; hover-8 — отмена без работы; hover-5/7/9 — Назад с исправленным центром. Фикстура предназначена для проверки оформления, реальные числа берутся из профиля.

Действия не обходят ограничения: при 3/3 новый заказ не добавляется, при полном складе хлеб не исчезает. Наведение и щелчок с объяснением доступны и в этих состояниях. Логические тесты отдельно проверяют успешные сбор/улучшение/отмену и безопасность отмены производства.
