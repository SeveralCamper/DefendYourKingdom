# QA-группа — P18: технические проверки UE5

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P18: технические проверки UE5

| ID | Проверка | Инвариант / результат |
|---|---|---|
| `P18-T01` | Переход город → бой → город | Раздельные уровни, постоянный профиль не теряется, боевые Actor уничтожаются |
| `P18-T02` | Время в бою ×1/×2/×3 и офлайн-производство | Городская экономика зависит от реального прошедшего времени, не от ускорения боя и не требует живых городских Actor |
| `P18-T03` | Одни и те же базовые значения из C++ для 10+ экземпляров | Один тип данных читается одинаково, изменяемое HP/эффекты индивидуальны, нет копии неполной таблицы в каждом методе |
| `P18-T04` | Добавить юнита с существующей механикой и изменить только исходные характеристики | Изменение в статическом каталоге после компиляции не требует переписывать Attack/Health/Targeting |
| `P18-T05` | Особый механизм берсерка / паладина | Узкое C++-расширение, без нового отдельного боевого движка для каждого типа |
| `P18-T06` | Физический урон 10 по броне 2; магический урон 10 по магической броне 2 | Итог 8 соответствующего типа; урон неотрицателен; два типа брони не смешиваются |
| `P18-T07` | Юнит одновременно атакует и находится под горением/замедлением | Жизненный цикл/действия/эффекты независимы, нет взрыва сочетаний enum |
| `P18-T08` | Два слушателя события смерти | Ресурс убийства начисляется ровно один раз владельцем транзакции, интерфейс обновляется по уведомлению |
| `P18-T09` | Редактировать исходники между прогонами | Не требуется отдельный runtime-редактор статов/панель; допускается пересборка; тестовый профиль работает независимо от обычного |
| `P18-T10` | Blueprint/UMG с реальным UE5.5 MCP | Записать обнаруженный набор функций, проверить реальное создание/изменение/компиляцию UI и AnimBP; только после этого утвердить UI-архитектуру |
| `P18-T11` | Тест утечек / висячих делегатов / повторных переходов | Используются UE Insights/Memory Insights, автоматические регрессии и безопасная работа с UObject и событиями; нулевое число известных ошибок по результатам прогонов |
