# Открытые поля и разрешённые рабочие значения

Этот перечень **не блокирует локальный DEV-MVP**, если поле можно временно заполнить `DEV_PLACEHOLDER` по [`DEV-MVP-EXEC`](tech/05-dev-mvp-policy.md). Он не заменяет строки `НУЖНО ЗАПОЛНИТЬ` в каждом паспорте.

| Объект | Что точно установлено | Что ещё нужно для финального контента | Политика разработческой сборки |
| --- | --- | --- | --- |
| Гоблин-убийца | 15 HP; обычный гоблин 10 HP; атака `2×3` | Тайминги отдельных ударов/анимаций | Не менять 15/10 или 2×3; незаданные интервалы только `DEV_PLACEHOLDER` |
| Первый шаман-босс | Стабильный `ContentId`: `FK-GOBLIN-SHAMAN-BOSS`; один из трёх боссов; первичные параметры в каталоге | Финальное отображаемое имя | Рабочее имя **«Тролль-шаман»**; не создавать отдельного типа или четвёртого босса |
| Орк-шаман | Аура +20% урона, радиус 10, однотипные ауры не суммируются | Окончательное округление дробной величины усиленного урона | Заменяемое банковское округление `DEV_PLACEHOLDER`, не выдавать за окончательное решение автора |
| Двойные атаки | Составляющие `2×3`, `2×6` в паспортах | Момент каждого попадания и его анимация | Сохранить числовые компоненты; не подменять одним увеличенным ударом |
| Боссы | Две фазы, переход на 50% HP, без подкреплений | Уникальные способности каждой фазы | Тестовые эффекты только с маркером `DEV_PLACEHOLDER` |
| Городские здания/исследования | Таймеры и очереди обязательны | Длительности и цены отдельных элементов | Короткие временные длительности и цены без отключения очереди |
| Ассеты типов | По каждому типу в его паспорте есть отдельные поля | `НУЖНО ЗАПОЛНИТЬ` для моделей/иконок/анимаций/VFX/SFX | Бесплатные лицензированные временные визуальные ресурсы; аудио в первой реализации не подключать |

**Правило чтения:** открытые поля конкретного типа искать **только в его паспорте**; не раскрывать все незаполненные поля перед каждым действием Codex. Нельзя интерпретировать `НУЖНО ЗАПОЛНИТЬ` как согласие автора на новую игровую механику.
