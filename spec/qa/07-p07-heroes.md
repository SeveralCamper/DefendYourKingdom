# QA-группа — P07: герои

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P07: герои

| ID | Подготовка / действие | Ожидаемый результат |
|---|---|---|
| `P07-T01` | Герой закрыт индивидуальным условием; открыть таверну | Видна причина недоступности, найм не осуществляется |
| `P07-T02` | Выполнить условие, открыть героя, перезагрузить игру | Герой остаётся доступным, повторный найм не нужен |
| `P07-T03` | Разместить 2 разных открытых героев, попробовать третьего | Третий герой игрока не размещается, припасы не расходуются |
| `P07-T04` | Разместить героя и попытаться создать его же второй экземпляр | Дубль отклонён |
| `P07-T05` | Войти на миссию с ограничением героя | Запрещённый герой недоступен только по правилу этой миссии |
| `P07-T06` | Загрузить миссию с авторским, ещё не открытым сюжетным героем | Сюжетный герой появляется, не меняет коллекцию и не занимает место в лимите двух героев игрока |
| `P07-T07` | Проверить слот: герой/обычный юнит | Обе категории используют одно правило совместимости объекта со слотом |
| `P07-T08` | В фазе подготовки выбрать героя | Виден способ покупки и стоимость в припасах; в городе цена боевого размещения не навязывается |
| `P07-T09` | Начать волну, герой бьёт первую допустимую цель по E09.03 | Выбор автоматический по очереди входа в радиус; ручной выбор врага отсутствует |
| `P07-T10` | Во время волны нажать кнопку над живым героем | Запущено умение, цель выбрана автоматически, второе действие пользователя не требуется |
| `P07-T11` | Не нажимать кнопку умения при готовом откате | Умение **не** активируется самостоятельно |
| `P07-T12` | Нажать умение, затем попытаться нажать снова до окончания cooldown | Второе применение невозможно; откат начинается с первого нажатия |
| `P07-T13` | Одновременно готовы навыки двух героев | Оба можно применять независимо друг от друга |
| `P07-T14` | Попытаться запустить умение в паузе и при подготовке | Умение не запускается |
| `P07-T15` | Закончить волну с неготовыми умениями | К новой волне откаты восстановлены, как в P03 |
| `P07-T16` | Бой с героем-носителем ауры; герой умирает | Пассивный бонус исчезает; по бесплатному воскрешению может восстановиться |
| `P07-T17` | Герой создаёт самостоятельный временный эффект и погибает | Эффект продолжает собственную установленную длительность |
| `P07-T18` | Если автор утвердил героя со специализацией на ловушках, проверить его эффект | Бонус применяется по утверждённому контенту. «Инженер» не является обязательным персонажем |
| `P07-T19` | Герой получает урон, погибает, откат заканчивается, игрок воскрешает | Бесплатное воскрешение с полным HP; метапрогрессия не меняется |
| `P07-T20` | Между волнами продать героя | 100% реально потраченных припасов возвращается, герой остаётся разблокированным |
| `P07-T21` | Повышать уровень героя в таверне, закрыть игру | Прирост постоянный, результат переживает перезапуск |
| `P07-T22` | Улучшить отдельно оружие/броню/способность | Изменяется указанная ветвь по будущим правилам; другие ветви не сбрасываются |
| `P07-T23` | Выбрать косметический скин | Меняется внешность, характеристики и навык остаются прежними |
| `P07-T24` | Открыть карточку, нажать на смену портрета/текста | Портрет заменяется биографией и возвращается обратно |
| `P07-T25` | Открыть город с несколькими нанятыми героями | Все доступны как визуальные NPC; их прогулки не блокируют боевое использование |
| `P07-T26` | Поднять скорость до ×2 и ×3, применить умение героя | Активация остаётся доступной по установленным правилам, анимации/время следуют общему масштабу |
| `P07-T27` | Закончить миссию с героем-источником бонуса | Постоянные городские улучшения не теряются при результате |
| `P07-T28` | Авторский сюжетный герой уже размещён на карте; игрок размещает двух своих разных героев | Оба героя игрока размещаются, сюжетный герой не учитывается в лимите 2; третий герой игрока блокируется |
| `P07-T29` | Предлагается косметический скин, созданный автором, с конкретным условием открытия | Скин разблокируется только по этому условию; платёжные интеграции не требуются |
