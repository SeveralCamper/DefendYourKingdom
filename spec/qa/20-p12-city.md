## P12: городская сетка и NPC

**Нормативный источник:** [`CITY12`](../01-city-and-meta.md#city1201--участки-территория-городская-сетка-approved-p12). Тесты для полного полигона `PROD-GATE-001`, включая отрицательные сценарии и повторную загрузку; не подтверждают фактическую реализацию.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| `P12-T01` | Создать начальный город | 25 участков схемой 5×5, из них ровно 6 открыты; каждый участок имеет сетку 10×10 |
| `P12-T02` | Попытаться разместить здание в закрытом участке/за границей | Действие отклонено без потери здания или ресурсов |
| `P12-T03` | Открыть соседний закрытый участок при выполненных его условиях | Участок открыт, строительная площадь доступна; нет требования идти по фиксированной очереди |
| `P12-T04` | Попытаться открыть не соседний участок, имея достаточные ресурсы | Отклонено, даже если остальные условия выполнены |
| `P12-T05` | Для двух участков задать разные авторские требования открытия | Каждый проверяет только собственную конфигурацию; условия не жёстко закодированы в одном виде |
| `P12-T06` | Повернуть здание 0/90/180/270 с несимметричным footprint | Занимаемая область поворачивается вместе со зданием; все занятые клетки валидируются |
| `P12-T07` | Установить здание с пересечением другого либо в недоступных клетках | Установка отклонена; состояние ранее размещённых объектов не повреждено |
| `P12-T08` | Построить уникальный функциональный тип и попытаться создать второй | Второй экземпляр не создаётся и не учитывается в инвентаре/сохранении |
| `P12-T09` | Не приобретать доступное из каталога функциональное здание | Редактор можно завершить; соответствующая функциональность без здания недоступна |
| `P12-T10` | При создании города проверить замок | Замок уже размещён; занимает весь участок 10×10 |
| `P12-T11` | Переставить замок на другой полностью доступный свободный участок | Замок перенесён бесплатно, без дублирования или потери |
| `P12-T12` | Попытаться перенести замок на частично занятый участок | Перенос отклонён; первоначальное здание сохраняется |
| `P12-T13` | Повернуть/улучшить функциональное здание с изменяемым внешним видом | Внешний вид меняется согласно типу/уровню, занятые клетки сохраняются |
| `P12-T14` | Бесплатно перенести обычное здание на совместимые свободные клетки | Стоимость перемещения 0; построенное здание не покупается повторно |
| `P12-T15` | Попытаться продать/безвозвратно удалить принадлежащее здание | Операций продажи/окончательного удаления нет; не производится возврат ресурсов и потеря здания |
| `P12-T16` | Убрать одно или несколько зданий во временное хранилище в редакторе | Клетки освобождены, здания остаются в собственности без дублирования |
| `P12-T17` | Завершить редактор с хотя бы одним неразмещённым принадлежащим зданием | Выход заблокирован до размещения всех имеющихся построек |
| `P12-T18` | Вернуть все здания из временного хранилища и завершить редактор | Выход допустим; позиции/повороты/открытые участки сохраняются корректно |
| `P12-T19` | Временно снять казармы/мастерскую/башню и восстановить | Изученные войска/ловушки/заклинания/улучшения остаются открытыми |
| `P12-T20` | Разместить два соседних здания и обновить декор | Вокруг каждого всегда полный периметр; общие дорожные клетки не дублируются. Корпус поверх чужого периметра и выход периметра за открытую землю запрещены |
| `P12-T21` | Перенести или временно снять здание, затем вернуть | Дорожки обновлены по новому расположению; они не влияют на производительность зданий и доступ к исследованиям |
| `P12-T22` | Появиться NPC на дороге в случайной точке, задать прогулку | NPC перемещается декоративно, не требует привязки к дому или распределения работников; при доступном прямом пути и альтернативе сохраняет направление в 80% решений; вынужденные повороты проверяются отдельно |
| `P12-T23` | Пара NPC появляется почти в одной точке дорожки, с управляемым случайным исходом | Только при условии близкого появления проверяется шанс 5%; при успехе NPC останавливаются, общаются и расходятся противоположно, без повторного срабатывания каждый кадр |
| `P12-T24` | Попытаться поставить декор/здание вне открытой рабочей зоны, при этом увидеть окружающий мир | Внешнее окружение видно, размещение любого объекта игроком запрещено |
| `P12-T25` | Перемещать камеру города во все стороны, по диагонали и отпустить ввод у границ | Точка обзора остаётся в области 7×7 вокруг строительных 5×5, включая инерцию; боевая камера не получает городских ограничений |
| `P12-T26` | Навести курсор на закрытый участок и перевести на кнопку окна у его середины | Нет нижней левой панели участков; окно привязано к середине участка, сокращает путь курсора к кнопке и показывает цену/условия/конкретные блокираторы, кнопка остаётся доступной при переходе курсора; открытие сохраняется однократно |
| `P12-T27` | Навести на несмежный, недоступный по условиям, открытый участок и внешний пояс; изменить масштаб/позицию камеры | Для закрытых указаны причины отказа и покупка запрещена; открытый участок/внешний пояс не предлагают покупку; окно следует за участком и остаётся в пределах экрана |
| `P12-T28` | Навести на кнопку перехода к миссии, панель ресурсов, сбор над зданием и стартовый экран; повторить при перекрытии с окном покупки | Другой HUD имеет приоритет: окно покупки сразу скрыто и не открывается сквозь HUD, ресурсы не списываются; переход к миссии работает. При возврате курсора на землю подсказка снова доступна; собственная кнопка покупки сохраняет интерактивность |

**Сохранить производственный гейт:** все эти сценарии — `PENDING IMPLEMENTATION`; уточнения строительства, производства и офлайна P13 находятся в `CITY13` и тестах P13 ниже.
