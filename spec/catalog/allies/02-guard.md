# ПАСПОРТ СОЮЗНИКА — Страж

**Общие правила и исследования:** [`10-player-units.md`](../../10-player-units.md). **Бой:** [`04-unit-combat.md`](../../04-unit-combat.md). **Заполненные параметры не менять без решения автора.**

## Страж — T2

| Поле | Значение |
| --- | --- |
| Имя | Страж |
| Сторона | Защитники игрока |
| Линия / тир | Пехота: крестьянин → страж → гвардеец / T2 |
| Боевая роль | Улучшенный обычный защитник; ближний бой; без особых способностей |
| Оружие | Копьё |
| Описание внешнего образа | Городской защитник со снаряжением заметно выше уровнем, чем у крестьянина. |
| Описание для карточки игрока | Страж королевства |

### Базовые параметры

| Поле | Значение |
| --- | --- |
| HP | 25 |
| Физическая броня — исходное значение | 1 |
| Магическая броня — исходное значение | 0 |
| Атака / урон за попадание | 7 |
| Вид урона | физический |
| Интервал атак | 1,5 с |
| Дальность атаки | 5 |
| Задержка нанесения урона | 0,3 с |
| Передвижение в бою | Не перемещается во время волны |
| Стоимость размещения | 5 припасов |
| Откат после смерти | 25 с |

### Атаки, эффекты и особые правила

| Поле | Значение |
| --- | --- |
| Основная атака | Копьё: 7 физический урона, интервал 1,5 с; радиус 5 |
| Выбор цели | Общий FIFO-пул допустимых целей в радиусе; сохраняет выбранную цель до смерти/выхода (кроме отдельно указанного особого умения). |
| Поражение по площади (основная атака) | Нет (если иное не указано отдельно) |
| Особая способность | Нет |
| Описание способности | Не предусмотрена |
| Триггер / интервал особой способности | — |
| Частота / длительность статусов | — |
| Дополнительные иммунитеты / ограничения | — |

### Открытие, развитие и стоимость

| Поле | Значение |
| --- | --- |
| Условия появления в каталоге | В первичной модели не заполняются |
| Изучение ступени | 500 еды + 300 древесины + 200 камня |
| Общие исследования линии | [Таблица общих исследований](../../10-player-units.md#общие-исследования-каждой-линии); доступны всем тирами линии после исследования. |
| Персональные исследования | Три параметра по 1 уровня(м); см. таблицу ниже. |
| Цена в припасах | Не зависит от тира в одной линии |

| Индивидуальное улучшение | Эффект | Стоимость |
| --- | --- | --- |
| Усиление здоровья | 1 уров. × (+10 HP) | Стоимость **каждого уровня**: 800 еды + 300 древесины + 500 камня |
| Усиление брони | 1 уров. × (+1 брони)* | Стоимость **каждого уровня**: 1000 еды + 900 древесины + 700 камня |
| Усиление урона | 1 уров. × (+2 урона) | Стоимость **каждого уровня**: 800 еды + 300 древесины + 500 камня |
