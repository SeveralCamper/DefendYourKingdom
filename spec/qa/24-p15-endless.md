# QA-группа — P15: бесконечная оборона

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P15: бесконечная оборона

**Разделять по контрольным точкам разработки:** `MVP` — проверяется перед MVP-приёмкой; `RELEASE` — необходим перед полноценным релизом соответствующей функции. Не объявлять тесты release-only обязательными для запуска MVP-заглушки. Бизнес-правила — только [`END15`](../02-mission-economy.md#end15--бесконечная-оборона-рейтинги-и-события-p15-approved).

| ID | Этап | Сценарий | Ожидаемый результат |
|---|---|---|---|
| P15-T01 | MVP | Замок 1-го уровня; попытка войти в endless | Вход ещё заблокирован |
| P15-T02 | MVP | Замок 2-го уровня; открыть endless | Вход доступен, без привязки к отдельной фракции |
| P15-T03 | MVP | Перейти в endless | Загрузка тестового поля с площадками расстановки; не требуется финальная отдельная карта |
| P15-T04 | MVP | Открыть/обработать описание события через общий механизм миссий | Каркас конфигурации пригоден для будущих временных миссий; реальное событие не создаётся |
| P15-T05 | MVP | Попытка начать создание финальной карты до `POLYGON_ACCEPTED` | Блокировка работ/приёмки в производственном плане |
| P15-T06 | RELEASE | Проверить состав очередных этапов endless | Сначала последовательные блоки фракций, затем смешанные; нет произвольного смешивания с первой волны |
| P15-T07 | RELEASE | Пройти более 1 волны на одной карте | Усложнение идёт без отдельного выбора сложности; волны формируются по утверждённым шаблонам |
| P15-T08 | RELEASE | Завершить волну; уйти в город | Начислена награда волны, состояние обороны и следующей волны сохранено |
| P15-T09 | RELEASE | Вернуться из города | Восстанавливается последняя зафиксированная расстановка/этап, нет старта с волны 1 |
| P15-T10 | RELEASE | Проиграть, когда защищаемая цель разрушена | Повтор начинается с **проваленной**, а не первой волны; точные ресурсы восстановлены согласно отдельно утверждённому checkpoint |
| P15-T11 | RELEASE | Нажать завершение волны дважды / симулировать сбой сохранения | Награды не дублируются, состояние волны фиксируется не более одного раза |
| P15-T12 | RELEASE | Проверить обычную кампанию после краша/выхода | Кампанийная попытка НЕ возобновляется из endless-checkpoint |
| P15-T13 | RELEASE | Наёмник задействован несколько волн | Не допускается бесконтрольная бессрочная работа стандартного контракта; конкретные правила после `TBD END15-MERCENARIES` |
| P15-T14 | RELEASE | Достигнуть порогов наград и повторить их | Разовые награды не дублируются; повторяемые начисляются только по утверждённым ограничениям |
| P15-T15 | RELEASE | Пройти волны офлайн, затем открыть игру онлайн | Локальное продвижение сохраняется; отправка в рейтинг обрабатывается только по утверждённой модели проверки |
| P15-T16 | RELEASE | Увеличить волны локальной подделкой сохранения | Поддельный результат не должен считаться **достоверным**, пока нет утверждённого сервера/проверки; разработка защиты `TBD END15-ONLINE-TRUST` |
| P15-T17 | RELEASE | Сравнить рейтинг двух игроков | Единственный результат — полностью пройденные волны; не используется скрытый tie-break по времени/убийствам |
| P15-T18 | RELEASE | Запустить временное событие с наградой, закончить срок | Событие больше недоступно, все полученные постоянные разблокировки сохранены |
| P15-T19 | RELEASE | Включить запусковое событие основателя | Уникальные звание и декор можно открыть по настроенным условиям; возможные скины/бонусы не создаются без утверждённого контента |
| P15-T20 | RELEASE | Проверить полный перечень кампаний | Вольные Кланы, Твари Подземья и Вторжение демонов присутствуют; все финальные карты/объекты прошли `CONTENT-GATE-001` и `PROD-GATE-001` |
| P15-T21 | DLC | Подключить второй город | Прогресс и таблица лидеров относятся к конкретному городу; это не обязательный тест первого релиза |

**Открытые блокеры release-only тестов:** `TBD END15-CHECKPOINT`, `END15-INTERRUPT`, `END15-MERCENARIES`, `END15-WAVES`, `END15-ONLINE-TRUST`, `END15-REWARDS`, `END15-EVENT-SCHEDULE`. **Ни один тест здесь не является PASS** до реализации и ручной проверки автора.
