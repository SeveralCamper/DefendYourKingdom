## P09: противники, волны и боссы

**Источник истины:** [`07-content-and-magic.md`, E09](../07-content-and-magic.md#p09--вольные-кланы-общий-ai-волны-и-боссы) и единая атака в [`04-unit-combat.md`](../04-unit-combat.md). Тестовые карты и демоданные допустимы **только на полигоне** до `POLYGON_ACCEPTED`; финальных карт кампании нет.

| ID | Проверка | Критерий |
|---|---|---|
| `P09-T01` | Конфигурация всех 13 идентификаторов Вольных Кланов | 4 гоблина, 4 орка, 2 мини-босса, 3 босса распознаются и имеют уникальные стабильные идентификаторы |
| `P09-T02` | Гоблин-убийца и гоблин-стрелок | Гоблин-убийца: 15 HP и серия атак `2×3`, обычный гоблин: 10 HP; гоблин-стрелок — дальняя атака и параметры собственного паспорта |
| `P09-T03` | Хоп-гоблин, орк-таран | Проверить актуальные паспорта: орк-таран 85 HP, 2 физической брони, 4 урона; хоп-гоблин — свои значения |
| `P09-T04` | Смертельный удар по берсерку | Первый такой удар оставляет 1 HP, следующий может убить; не повторяется бесконечно |
| `P09-T05` | Орк-шаман: два перекрывающихся усиления | Однотипная аура не удваивает урон, источник определяет только одну итоговую силу эффекта |
| `P09-T06` | Тролль и огр | Тролль: регенерация + ближний AoE; огр: высокий HP и атака одной цели; численные статы только после P10 |
| `P09-T07` | Два защитника входят в дальность одного врага последовательно | Враг бьёт первого попавшего в пул до потери допустимости; не перехватывает более близкого второго |
| `P09-T08` | Два врага входят в радиус одного защитника последовательно | Защитник бьёт первого, затем следующего; тот же механизм, что у врага |
| `P09-T09` | Два входа целей в один тик | У каждой атакующей единицы стабильный, воспроизводимый порядок; нет случайного выбора |
| `P09-T10` | Цель умерла, вышла из радиуса, удалена или воскресла | Очередь очищается без висячих ссылок/двойных целей; восстановленная цель регистрируется при допустимости |
| `P09-T11` | Во время замаха цель вышла из области | Текущий удар достигает цели по P05; новая атака по недопустимой цели не начинается |
| `P09-T12` | Враг атакует защищаемый объект, защитник воскресает в дальности | Немедленно переключает допустимую боевую активность на защитника; без защитников продолжает удары по объекту |
| `P09-T13` | Вражеский стрелок в действии | Останавливается при выборе цели, стреляет, после устранения целей продолжает маршрут |
| `P09-T14` | Вражеская поддержка лечит/усиливает нескольких союзников | Эффект по области; однотипные наложения от разных источников не суммируются; поддержка также способна атаковать |
| `P09-T15` | Два разных отряда получают один и тот же маршрут | Используют одинаковую логику движения, разные назначенные полосы/строи/позиции спавна |
| `P09-T16` | Тестовый летающий враг | Полёт по заданной воздушной траектории функционирует; не числится обязательным врагом Вольных Кланов |
| `P09-T17` | Повторное прохождение одной авторской тестовой волны | Одинаковый состав, формация 1/2/3, интервалы, точки и порядок групп; нет случайной замены |
| `P09-T18` | Вражеский призыватель | Останавливается, призывает существ по авторскому порядку, назначает предопределённый маршрут; логика маршрута общая |
| `P09-T19` | Убить призванного врага | Учитывается в числе реальных убийств, 0 ресурса ловушек, несмотря на ловушку/AoE |
| `P09-T20` | Убить призывателя с живыми призванными врагами | Зависимые исчезают; не засчитываются как убийства игроком при деспавне; нет ресурса ловушек |
| `P09-T21` | Дополнительная группа по событию в середине волны | Настраиваемое условие запускает одну группу и не повторяет спавн при повторных событиях/сбое подписки |
| `P09-T22` | Последний враг умер, но впереди ещё условная группа | Волна ждёт допустимый спавн, но при невыполнимом условии корректно закрывает ожидание по авторской настройке; без вечного зависания |
| `P09-T23` | Переход фаз босса по HP | При пересечении порога событие срабатывает однократно, сохраняется единый HP, отрабатываются авторские действия демосценария |
| `P09-T24` | Повторный запуск/выход из миссии при ожидающих событиях | Старые подписчики/группы не действуют в новой попытке, нет ошибочных вторичных вызовов |
| `P09-T25` | Впервые встретить врага и проиграть/прервать миссию | Запись бестиария навсегда открыта и сохранена в локальном профиле, без награды за поражение |
| `P09-T26` | Повторить миссию, встретить уже открытого врага | Окно знакомства второй раз автоматически не показывается; карточка доступна вручную |
| `P09-T27` | Разные враги и раскрытые направления | Записи бестиария персистентны, скрытые входы сбрасываются при новом запуске миссии |
| `P09-T28` | Карточка врага | Модель, описание, статы, атака, способности и иммунитеты отображаются из действительных данных, не самостоятельного набора чисел в UI |
| `P09-T29` | Одна карта по разным сложностям / спецправила | Спавн/маршруты/запреты определяются авторскими данными, не случайным выбором |
| `P09-T30` | Испытать все 13 типов врагов с полным пулом обороны | Все реальные классы поведения/AI и взаимодействия должны быть подтверждены до авторской приёмки; способности боссов требуют отдельного согласования до финальной реализации |

**Проверка отдельного требования P11:** структура кампании Вольных Кланов рассчитана на девять уникальных миссий с боссами в 3/6/9, но **не создаёт реальные карты до прохождения полного полигона**. Проверяется конфигурация/схема без изготовления карт.
