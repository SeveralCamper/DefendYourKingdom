**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P11: кампании, режимы и награды

**Нормативный источник:** [`CAM11`](../02-mission-economy.md#d-кампании-режимы-звёзды-и-постоянные-награды--p11-approved). Тесты используют искусственные определения миссий в **полигоне**; не требуют создания финальных 9+3 карт до `POLYGON_ACCEPTED`.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| `P11-T01` | Открыта M01, победить на любой основной сложности | Становится доступна M02; ранее пройденную M01 можно запускать повторно |
| `P11-T02` | Победить в M02, M05, M08 | После каждой победы становится **видна** соответствующая бонусная миссия; до победы соответствующая ветка скрыта |
| `P11-T03` | Автор задаёт двухступенчатое бонусное ответвление тестовой миссии | Граф поддерживает глубину 2; не создаёт автоматически второй реальный уровень |
| `P11-T04` | Победить все M01…M09 на разных основных сложностях, не проходя бонусные | Следующая кампания открыта; от бонусных миссий не зависит |
| `P11-T05` | Впервые открыть одну миссию | EASY/HARD/NIGHTMARE доступны сразу; испытания 4/5 закрыты |
| `P11-T06` | Победить только на NIGHTMARE | Разблокированы **оба** испытания 4 и 5; не требуется сначала проходить 4 для открытия 5 |
| `P11-T07` | Одна миссия с профилями разной сложности | Состав и число врагов соответствуют авторским профилям; HP и урон модифицируются по единой модели; маршруты меняются только при настройке |
| `P11-T08` | Испытание запрещает стрелков, ловушки, отдельное заклинание и героев | Размещение/применение запрещённых категорий блокируется; разрешённый контент доступен; условия победы берутся из испытания |
| `P11-T09` | Испытание требует иного условия победы | Победа/поражение следуют авторскому предикату, не жёстко фиксированному правилу обычной миссии |
| `P11-T10` | Победить с HP_RATIO = 0.60 и = 0.90 | Ровно 60% дают 1★, ровно 90% дают 2★; пороги **строго больше**, не `>=` |
| `P11-T11` | Победить с HP_RATIO = 0.61 и = 0.91 на нескольких обязательных объектах | Суммарный остаток HP по сумме максимальных HP всех защищаемых объектов даёт 2★ и 3★ соответственно |
| `P11-T12` | Победить с 1★, затем повторить с 3★, затем снова с 3★ | Лучший сохранённый результат растёт до 3★ только один раз; звёзды не фармятся повторениями |
| `P11-T13` | Пройти NIGHTMARE первым | Единожды начислены одноразовые награды EASY, HARD, NIGHTMARE; награды испытаний отдельно и не подмешиваются |
| `P11-T14` | Пройти EASY/HARD, затем NIGHTMARE; повторно открыть экран результатов | Уже полученные награды не дублируются; начисляются лишь ранее невыданные |
| `P11-T15` | Победа и затем поражение/прерывание/повторная попытка/двойной callback результата | Награды выдаются транзакционно единожды только за победу; поражение/прерывание не выдают ничего |
| `P11-T16` | Утвердить любую ресурсную сущность в награду отдельного режима | Разовая награда выдаётся по сконфигурированному типу и количеству, без ограниченного хардкод-списка валют |
| `P11-T17` | Переиграть миссию после получения разовой награды | Повторяемых ресурсов автоматически нет: система ожидает отдельного одобренного правила (`TBD`) |
| `P11-T18` | Установить порог N звёзд для тестовой награды; перейти порог и повторить | Триггер срабатывает при достижении и выдаёт награду однократно; без авторской конфигурации никаких наград не создаётся |
| `P11-T19` | Первую основную миссию пройти новичком | Встроенное обучение следует доступности механик; нет обязательной отдельной обучающей карты |
| `P11-T20` | Запустить обычную миссию с защищаемой таверной 50 HP и ещё одним объектом, затем ту же миссию в `CHALLENGE_5` | В основном режиме HP таверны 50; в `CHALLENGE_5` у **каждого** защищаемого объекта MaxHP=HP=1. Союзные юниты сохраняют обычные HP/воскрешение; перезапуск миссии разрешён. При потере обязательного объекта действует прежнее условие поражения. |
| `P11-T21` | Выдать отдельную награду за завершение кампании, настроив её в тестовом контенте | Разовая кампания награждает по настроенному событию; при отсутствии настройки ничего не начисляется |
| `P11-T22` | Прочитать сохранение после победы, затем перезапустить игру | `CompletedModes`, `BestStars`, `ClaimedRewards` устойчивы; HP и время прохождения как рекорды не сохраняются |

Проверить на полном полигоне до утверждения `PROD-GATE-001`; все сценарии пока `PENDING IMPLEMENTATION`.
