|---|---|---|
| P06-T01 | Установить ловушку с конфигурацией 3 использования | Показан полный запас 3; источник ресурса перезарядки не расходуется |
| P06-T02 | Провести одного врага через три отдельных законченных цикла | Остаток последовательно 3→2→1→0; после третьего цикла ручная перезарядка |

| P06-T10 | Счётчик равен нулю, ресурса недостаточно | Иконка затемнена/неактивна, ресурсы и состояние без изменений |
| P06-T11 | Враг уже стоит в зоне после окончания перезарядки | Ловушка автоматически инициирует срабатывание снова |

| P06-T15 | Попытаться продать ловушку при 0 | Отказ, сообщение о необходимости перезарядки |
| P06-T16 | После расхода валюты восстановить и продать допустимую ловушку | Возврат ровно 100% припасов, без возврата валюты перезарядки |
| P06-T17 | Продажа при `0<remaining<max` | Продажа отклонена, объект/слот/баланс не изменены (`GD-DEC-082`) |
| P06-T18 | Враги атакуют ловушку/башню | Не изменяют HP неуязвимых объектов |
| P06-T19 | Башня с двумя независимыми атакующими | Каждый выбирает цель и атакует со своим откатом; могут выбрать одну |
| P06-T20 | Игрок установил башню, затем хочет изменить позицию между волнами | Прямого переноса нет: продажа с возвратом припасов → новая покупка в совместимом слоте |
| P06-T21 | Башня предварительно установлена дизайнером карты | Обычных кнопок покупки/продажи/перестановки нет |
| P06-T22 | Авторская ловушка или отряд уже присутствует на карте | Игрок не может купить/переставить/продать, несмотря на визуальное присутствие |
| P06-T23 | Баррикада с несколькими гномами под атаками | Один пул HP; независимые атаки гномов; никаких отдельных HP без новой спецификации |
| P06-T24 | Изучить элитную ловушку, затем открыть выбор в HUD | Все изученные младшие версии доступны; лучший открытый по умолчанию |
| P06-T25 | Выбрать младшую изученную ступень обычного юнита через **стрелочку над типом** | Размещается выбранная ступень, не заменяется автоматически элитой; интерфейс выбора ступеней ловушек отдельно TBD |

| P06-T27 | Городской бонус к шипам, поставить несколько экземпляров | Каждый соответствующий экземпляр получает бонус ровно по правилам P14 |
| P06-T28 | Миссия имеет особую ловушку без городского открытия | Доступна только при явном предоставлении миссией |

| P06-T31 | Сохранить/перезапустить миссию после использований и трат | Нет возврата израсходованной контрактной/валютной экономики вне установленных правил P02/P03 |
| P06-T32 | 15+ врагов визуально наложены в одной области ловушки | Правильный AoE по всем целям без зависимости от маршрутов и их коллизии |
