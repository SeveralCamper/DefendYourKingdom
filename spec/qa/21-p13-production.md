# QA-группа — P13: ресурсы, строители, офлайн

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P13: ресурсы, строители, офлайн

| ID | Сценарий | Приёмочный результат |
|---|---|---|
| `P13-T01` | Создать новый профиль | На карте размещены замок, лесопилка, каменоломня, мельница, 1 дом; нет лишних экземпляров |
| `P13-T02` | Оставить производителя без заказов, затем поставить заказ с пустым ресурсным балансом | Без заказа прироста нет; заказ не потребляет другие ресурсы, результат остаётся в здании до ручного сбора |
| `P13-T03` | Попытаться собрать до 60 секунд, затем после 60 секунд | До минуты сбор недоступен, после накопления доступен по утверждённым условиям |
| `P13-T04` | Поставить три заказа в производителе уровня 1, дождаться завершения, не собирать | Нет автоматически созданных новых заказов; внутренний запас ограничен количественной ёмкостью, остаток готового заказа не теряется |
| `P13-T05` | Производители уровней 2/3 с разными очередями, длительный офлайн | Каждый независимо выполняет только поставленные заказы; вместимость и ожидающий остаток не переполняются |
| `P13-T06` | Две лесопилки, разные уровни и остатки, загрузка/перезапуск | Раздельные объёмы, время и уровни; нет слияния/дублирования |
| `P13-T07` | Заполнить склад древесины, оставить свободными пищу и камень | Древесина не собирается, накопление внутри лесопилки идёт до собственного предела; сбор других ресурсов доступен |
| `P13-T08` | Освободить место на складе после переполнения | Доступный накопленный ресурс можно получить без потерь по согласованному правилу сбора |
| `P13-T09` | Сравнить вместимость двух уровней склада и собрать при остатке места меньше накопленного | Каждый уровень добавляет по 2000 к вместимости еды, древесины, камня и железа. На склад помещается только свободная часть, остальное остаётся в здании |
| `P13-T10` | Завершить миссию с наградой, не помещающейся в склад | Не влезшая часть доступна через «Собрать награды» конкретной кампании; не теряется |
| `P13-T11` | Повторно нажать «Собрать награды», перезагрузить профиль | Нет повторной выдачи уже полученного; невыданное устойчиво сохраняется |
| `P13-T12` | Дом уровня 1 завершил цикл | В доме накоплена одна монета, следующая не производится до сбора; общий баланс не растёт сам |
| `P13-T13` | Разблокировать дублирующие ресурсные здания при увеличении уровня замка | Число экземпляров ограничено данными замка, не общим запретом «один тип = один экземпляр» |
| `P13-T14` | Разместить дублирующие лесопилки, затем снять их в редакторе | Все экземпляры обязательны к размещению перед выходом, позиции и остатки раздельны |
| `P13-T15` | При утверждённых таймерах (Q40) построить два задания при достаточном числе строителей; третье поставить в очередь | Выполняется не больше открытого числа строителей; будущая заявка не считается оплаченной/завершённой |
| `P13-T16` | Начать и отменить стройку / улучшение по таймеру | Стоимость списана один раз при старте; при отмене полностью возвращена один раз |
| `P13-T17` | Отменить ещё не оплаченную заявку из очереди | Нет начисления несуществующего возврата или двойного платежа |
| `P13-T18` | Улучшать лесопилку с активным заказом и собирать ресурс | Активный заказ сохраняет зафиксированные параметры; очередь/накопленное сохранены, новые лимиты действуют после завершения улучшения |
| `P13-T19` | В редакторе временно снять производящее здание с уже идущим таймером | Текущие таймеры идут; при восстановлении размещения прогресс сохранён |
| `P13-T20` | Поставить заказы, закрыть игру на 30 часов, снова запустить | Заказы прошли по фактическим временным границам, остатки сохранены, новых заявок нет; дом ограничен одним золотым циклом, общего офлайн-лимита нет |
| `P13-T21` | Сохранить/загрузить ресурсы и невостребованные награды, очередь строительства и незавершённые исследования | Состояние и временные отметки восстановлены, ресурсы, стройка и исследования не начислены/завершены дважды |
| `P13-T22` | Достигнуть `uint32` предела специального ресурса | Значение не переполняется в ноль и не уходит в отрицательное; политика превышения требует реализации P18 |
| `P13-T23` | Изменить локальные часы вперёд/назад и попытаться заявить онлайн-рекорд | **BLOCKED до `P18-TIME-TRUST`**; в QA требуется отдельный тест утверждённой модели доверенного времени и рейтинг-валидации |
| `P13-T24` | Проходить без получения третьего (платного) строителя | Основной прогресс проекта не должен зависеть от неприобретённого рабочего; финальная экономика уточняется в P14 |
| `P13-T25` | **Если выбран режим с таймерами:** завершить стройку во время перестановки в редакторе | Сохранён детерминированный результат, не потеряны здания/таймеры; уточнить P18 |

**Не менять гейт:** эта группа, P12-T01…T24 и `PG-055`/`PG-056` проверяются на едином полном полигоне до `POLYGON_ACCEPTED`. Несогласованные `TBD` нельзя превращать в «pass» на основании самодельных допущений.
