# Пекарня — снимки настоящего UMG

`first.png` (440×550) и `interior.png` (960×720) получены тестом `DYK.BakeryHUD.RenderReferenceWindows` через D3D11/FWidgetRenderer. Это тот же UDYKResourceBuildingWidget, который создаётся игровым адаптером; изображения после экспорта не редактировались. Фон прозрачный.

Визуальная фикстура: накоплено 2150, очередь 1/3, осталось 53 мин 24 с. Эти числа не являются новым балансом и не подменяют данные игры: адаптер получает их из профиля выбранного здания. Проверка использует линейный render target с однократным кодированием в sRGB; автоматически сверяются цвет пергамента и прозрачность угла.

Сопоставлено с двумя точными вложениями автора: общие кнопки и надписи сохранены буквальными срезами; динамические числа лежат в очищенных областях, остальные надписи и описание — непосредственно из референса. Снимки подтверждают внешний вид отдельных окон. Проекционное положение карточки на здании проверено алгоритмически, а удобство взаимодействия в городе требует авторского игрового ревью.
