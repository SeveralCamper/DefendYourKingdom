# QA-группа — P04: маршруты и слоты

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P04: маршруты и слоты

| ID | Сценарий | Ожидание |
|---|---|---|
| P04-T01 | Две дороги + объединение + поворот | Враги следуют заданным маршрутам, без случайного выбора |
| P04-T02 | Точка спавна в центре карты | Во время первого появления вход раскрывается; его видят при подготовке следующих волн той же попытки; при полном рестарте снова скрыт |
| P04-T03 | Маршрут вверх/вниз с перепадом высоты | 3D-модель проходит и поворачивается согласно траектории |
| P04-T04 | Три гоблина в одном поперечном строю | Визуально до 3 по ширине; следом могут идти другие |
| P04-T05 | Два огра и один босс | Огр может быть в группе до 2, босс — одиночно |
| P04-T06 | Быстрый гоблин позади медленного огра | Гоблин свободно обгоняет/пересекает модель без ожидания |
| P04-T07 | Передний враг атакует союзника, задние продолжают | Допустимо наложение врагов и коллективная атака |
| P04-T08 | У одного защитника 15+ врагов | Все враги в радиусе имеют право атаковать |
| P04-T09 | Два союзника поперёк дороги и враги на трёх линиях | У каждого союзника работает зона атаки и собственный выбор цели |
| P04-T10 | Поднять защитника позади прошедшего врага | При досягаемости враг может остановиться и вновь атаковать |
| P04-T11 | Враг достигает защищаемой цели | Не исчезает, наносит повторные удары до гибели одной стороны |
| P04-T12 | У цели 1 HP, враг ударил | Поражение без фиктивного «достижения цели» и удаления врага |
| P04-T13 | На карте есть несколько целей | При разрушении любого обязательного объекта — немедленное поражение; вторая цель может быть цела |
| P04-T14 | Стрелок в стандартном слоте типа «юнит» | Проверяется фактическая дальность атаки, а не особый вид слота: атакуется только противник в радиусе |
| P04-T15 | Размещение в неподходящем типе слота | Отказ для любого несовместимого объекта (юнит, наёмник, ловушка, башня), без траты припасов/контрактов |
| P04-T16 | Некромант и три скелета на виртуальных точках | Не требуются пользовательские боевые слоты |
| P04-T17 | Скелетики погибли частично, некромант жив | В тестовом примере призывателя через настроенный цикл возрождаются погибшие существа, выжившие лечатся |
| P04-T18 | Некромант погиб | Все созданные им скелеты исчезают |
| P04-T19 | Башня и враг в радиусе за декоративной стеной | Башня атакует без требования line-of-sight |
| P04-T20 | Непустой слот занят | Подсветка пустоты исчезает, меню по клику доступно |
| P04-T21 | Изменить позицию бойца между волнами | Прямого переноса нет (P16): продать → выбрать любой свободный совместимый слот → разместить заново |
| P04-T22 | Уровень больше экрана | Камера перемещается без изменения фиксированного угла |
| P04-T23 | Сложность включает дополнительный маршрут | Реально меняется доступный набор спавнов согласно данным |
| P04-T24 | Исключение из слотов / спецмиссия | Поддерживается локальная конфигурация условий |
| P04-T25 | Попытка сделать баррикаду как физический NavMesh тупик | Не требуется, враги атакуют объект по обычному правилу и проходят при его отсутствии |
| P04-T26 | Запуск финальной кампанийной карты до приёмки полигона | Задача не должна быть разрешена в плане/статусе сборки |
| P04-T27 | Продать/переместить обычного наёмника и крупную наёмную конструкцию | Обычный вариант совместим с обычным слотом; крупный — только с авторской площадкой, разрешающей именно этот объект; особых правил «класс всех наёмников» нет |
| P04-T28 | Две площадки с одинаковой меткой 2×3, но разными размерами/поворотом в мире | Каждая корректно работает по своим данным, общая сетка не создаётся |
| P04-T29 | Отдельная сетка города и боевые площадки | Размещение в бою не зависит от клеток городской сетки |
| P04-T30 | Перезапуск миссии после открытия скрытой точки | Скрытое направление снова неизвестно; профиль не содержит постоянной отметки раскрытия |
