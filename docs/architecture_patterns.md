# 📐 Архитектурные паттерны проекта

Чтобы избежать разрастания контекста (context bloat) и «спагетти-кода», строго следуй данным паттернам, адаптированным под UE5.

## 1. Data-Driven Design (Проектирование на основе данных)
* **Цель:** Полное отделение игрового баланса от структурного C++ кода.
* **Реализация:**
  * Все характеристики юнитов, башен и волн должны наследоваться от структуры `FCombatUnitRow` (хранится в `UDataTable`) или контейнеров конфигурации на базе `UDataAsset` (например, `UTowerDataAsset`).
  * **Правило:** Никаких хардкод-значений здоровья, урона или скорости внутри C++ конструкторов.

## 2. Гибридный паттерн Entity-Component (Нативный подход UE5)
* **Цель:** Масштабируемая реализация типов врагов и вариантов башен без иерархий глубокого наследования.
* **Реализация:**
  * Используй `AActor` в качестве базовой оболочки сущности.
  * Делегируй специализированную логику компонентам `UActorComponent`:
    * `UHealthComponent`: Отвечает за здоровье, сопротивление типам урона и события смерти.
    * `UTargetingComponent`: Сканирует врагов в радиусе атаки с помощью оптимизированных сферических коллизий (Sphere Queries).
    * `UAttackComponent`: Управляет кулдаунами оружия, спавном снарядов и нанесением урона.

## 3. Паттерн Abstract Factory (Абстрактная фабрика) для спавна
* **Цель:** Изоляция логики создания объектов от менеджеров боевой сессии.
* **Реализация:**
  * Центральный класс `ACombatFactory` считывает ID конфигурации из `UDataAsset` и безопасно инстанцирует соответствующий `AActor` (Башню, Защитника или Врага).
  * Blueprint-классы запрещены. Фабрика создаёт нативные C++ классы, а визуальные ассеты передаются в конфигурации C++ через `UDataAsset` или загружаются через `ConstructorHelpers::FObjectFinder`.

## 4. Паттерн Observer (Наблюдатель) через Dynamic Delegates
* **Цель:** Чистая отвязка игровой логики от UI и локального сохранения.
* **Реализация:**
  * Для C++-подписчиков используй подходящие нативные делегаты UE; не вводи Blueprint-события.
  * *Пример:* `UHealthComponent` транслирует событие `OnDeath`. Класс `AWaveManager` подписывается для обновления живых врагов, экономика начисляет доблесть, а C++ UI обновляет показания.
