# QA-группа — P16: интерфейс и управление

**Загружать только при проверке затронутой системы.** Общий перечень и поиск ID — [`09-qa.md`](../09-qa.md) и [`test-index.tsv`](test-index.tsv).

## P16: интерфейс и управление

**Нормативные требования:** `CITY16` в `01-city-and-meta.md` и `UI16` в `02-mission-economy.md`; P16 уточняет прежний P02/P03/P04/P06 запретив прямой перенос защиты даже в подготовке. Проверять отдельно от финансовых инвариантов P02, слотов P04 и постоянного прогресса P15.

| ID | Сценарий | Критерий принятия |
|---|---|---|
| P16-T01 | Открыть город и проверить верхнюю панель | Пища, древесина, камень и золото постоянно видны |
| P16-T02 | Несколько добывающих зданий накопили ресурсы | Над каждым свой сбор; кнопки «Собрать всё» нет |
| P16-T03 | Попытаться собрать до 1 минуты; собрать после | До порога нельзя; после порога ручной сбор доступен с учётом вместимости |
| P16-T04 | Открыть каталог и выбрать закрытое здание | Видны и открытые, и закрытые типы; закрытый показывает авторские условия |
| P16-T05 | Нажать на здание → «Переместить» | Вход в редактор; текущая городская расстановка не изменена до Apply |
| P16-T06 | Переместить/повернуть несколько зданий → «Отменить» | Все здания возвращаются точно в исходное положение; нет частичного сохранения |
| P16-T07 | Убрать одно принадлежащее непроданное здание (функциональное или декоративное) в буфер → «Применить» | Выход/коммит заблокирован, исходное сохранение не затронуто |
| P16-T08 | Выставить все функциональные здания и нажать Apply | Совместимость/свободные клетки проверены; все изменения применены одной транзакцией |
| P16-T09 | Выбрать недоступную основную миссию | Нажатие игнорируется; бонусная миссия до открытия вообще скрыта |
| P16-T10 | Нажать на пустую площадку в подготовке | Выбор объектов ограничен совместимостью и доступностью именно этого слота |
| P16-T11 | Попытаться напрямую перетащить защитника/героя/ловушку на другой слот между волнами | Ничего не переносится; нет команды «Переместить» |
| P16-T12 | Продать обычного юнита и разместить на другой площадке | Возврат 100% его цены и новая покупка на совместимый свободный слот; без штрафа |
| P16-T13 | Продать уже активированного наёмника и разместить в другом месте | Его контракт не восстанавливается/повторно не списывается; нельзя иметь один экземпляр в двух слотах |
| P16-T14 | Попытаться продать ловушку 1/3 или 2/3 заряда для переноса | Продажа заблокирована; новая покупка через прямой перенос недоступна; после полного заряда возможно продать |
| P16-T15 | Проверить HUD волны на разных масштабах камеры | Волна/всего, HP всех обязательных объектов, припасы, валюта ловушек, скорость всегда видны |
| P16-T16 | Во время волны пытаться узнать остаток ещё не появившихся врагов | Счётчика оставшихся врагов нет; будущий состав не раскрывается |
| P16-T17 | Плотная сцена, камера максимально отдалена | Важные индикаторы союзников, врагов, ловушек и героев не исчезают по LOD/зуму |
| P16-T18 | Впервые встретить тип врага | Небольшой попап не ставит игру на паузу; по клику открывается описание |
| P16-T19 | Не нажимать на попап нового врага 10 с | Попап исчезает, иконка бестиария отмечается «!»; запись доступна постоянно |
| P16-T20 | Повторно встретить тот же тип врага в другой попытке/после поражения | Повторный попап не появляется; запись бестиария сохранена |
| P16-T21 | Победить, когда часть ресурса награды не помещается | Окно результата показывает начисленное и отложенное; ничего не теряется/не выдаётся дважды |
| P16-T22 | Нажать «Покинуть», «Начать заново», «Отказаться от незавершённого боя» | Для каждого действия подтверждение с последствиями; отказ оставляет текущую сессию без изменений |
| P16-T23 | Разместить обычного юнита, использовать магию, перезарядить ловушку | Не возникают лишние диалоги подтверждения |
| P16-T24 | Первая основная миссия, начало и отключение подсказок | Подсказки доступны; «Убрать подсказки» скрывает их; отдельной библиотеки уроков нет |
| P16-T25 | Перейти в режим испытания 4/5 | Подсказки обучения не появляются |
| P16-T26 | На замке 2-го уровня открыть MVP endless, поставить оборону и завершить несколько тестовых волн | Реальный запуск волн и базовая боевая логика работают; не просто статический экран |
| P16-T27 | После очищенной тестовой волны выйти из endless в город и вернуться | Сохраняются расстановка и номер следующей тестовой волны; нет самовольного сброса на волну 1 |
| P16-T28 | MVP без настроенных событий | Иконка событий видима; открывается пустое окно «Нет активных событий»; реальное событие не создаётся |

**Готовность:** все `P16-T01…T28` имеют статус `NOT_RUN`, пока автор не проведёт приёмку. Дополнительная UI-проверка P17/P18: несколько языков, длинные строки, кнопки на разных разрешениях — конкретный набор локализаций ещё TBD. Не утверждать обязательное переназначение хоткеев или отдельный экран уроков.
