## Крестьянин — T1

| Поле | Значение |
| --- | --- |
| Имя | Крестьянин |
| Сторона | Защитники игрока |
| Линия / тир | Пехота: крестьянин → страж → гвардеец / T1 |
| Боевая роль | Самый первый обычный защитник; ближний бой; без особых способностей |
| Оружие | Вилы |
| Описание внешнего образа | Бедно экипированный ополченец; детали образа **НУЖНО ЗАПОЛНИТЬ** при художественной проработке. |
| Описание для карточки игрока | Обычный рабочий мужик взял вилы в руки для защиты своей деревни |

### Открытие, развитие и стоимость

| Поле | Значение |
| --- | --- |
| Условия появления в каталоге | Доступны сразу |
| Изучение ступени | T1: начальная ступень линии |
| Общие исследования линии | [Таблица общих исследований](../../10-player-units.md#общие-исследования-каждой-линии); доступны всем тирами линии после исследования. |

В казармах доступны три одноступенчатых улучшения крестьянина. Каждое занимает 20 с.

| Улучшение | Бонус после завершения |
| --- | --- |
| Здоровье | +5 HP |
| Урон | +2 урона за попадание |
| Броня | +1 физической брони, без изменения магической |

Бонус входит в характеристики крестьянина в городе и в бою. Цена пока задана как `DEV_PLACEHOLDER`.
